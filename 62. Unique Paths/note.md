# 62. Unique Paths
神秘小学奥数，然后有个解析解

---

### 解析解：C(m+n−2, m−1)

从左上走到右下，一共 m−1 步往下、n−1 步往右，总步数固定是 m+n−2。不同路径的区别只在于**哪几步是往下的**，所以答案就是从 m+n−2 步里挑 m−1 步往下。

DP 的 `dp[i][j] = dp[i-1][j] + dp[i][j-1]` 就是帕斯卡三角形的递推，那张 dp 表是一个斜着放的杨辉三角，两种解法算的是同一个数。

| 解法 | 时间 | 空间 |
|---|---|---|
| 二维 DP（sol.py） | O(mn) | O(mn) |
| 滚动一行 | O(mn) | O(n) |
| 组合数（sol2.py） | O(min(m, n)) | O(1) |

例子：m = 3, n = 7 → N = 8, k = 2

| i | 计算 | res | 此时等于 |
|---|---|---|---|
| 1 | 1 × 7 // 1 | 7 | C(7, 1) |
| 2 | 7 × 8 // 2 | 28 | C(8, 2) |

> 连乘算组合数一定**先乘再整除**：每轮结束时 res 都是 C(N−k+i, i)，必为整数，`//` 不丢余数。先除再乘（比如 7 // 2）就错了。

Python 能用库就直接 `math.comb(m + n - 2, m - 1)`；整数不溢出，m, n ≤ 100 也不用担心精度。
