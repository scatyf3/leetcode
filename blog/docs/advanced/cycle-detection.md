# 判环

## 一句话

有向图、无向图、网格，判环的办法各不相同；问「最短的环」又是另一回事。

## 怎么认出这类题

问「是否存在环」「最短的环有多长」「哪些点永远不会走进环」。

建在 L3 的：[DFS](../paradigms/dfs) · [BFS](../paradigms/bfs) · [图](../structures/graph)
