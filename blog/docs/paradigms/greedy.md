# 贪心

贪心的代码通常不到十行：排个序，扫一遍，每一步当场拍板，从不回头。难点不在写，在证明：
把「为什么这么选不会更差」写成**一句能证伪的话** —— 具体到能拿小数据去打它的命题，
比如「存在一个最优解包含右端点最小的那个区间」，而不是「每步选最好的」。
写出这句话之后只有两种结局：要么证得出来，要么对拍几百组当场被打脸。两种都比「感觉挺对」强。

贪心和 DP 的分界（候选数退化成 1、「有没有候选被**永久排除**」）在 [1d-dp.md](1d-dp.md) §4 讲过，
这里不重复，只讲那句话怎么写、怎么证、证不出来怎么打。

## 1. 先把那句话写出来

仓库里的贪心题，每道都能压成一句。右边一列是「换一个看着也合理的选法」，它就是那句话的反面，
一个小反例就能打死：

| 题 | 那句话 | 看着也合理的选法 → 反例 |
|---|---|---|
| 435 | 存在一个最优解包含**右端点最小**的区间 | 按 start 排：`[1,100] [2,3] [4,5]` 得 1，最优 2 |
| 11 | **矮的那根**和剩下任何柱子配对，面积都不超过刚结算的这对 | 挪高的那根：`[1,8,6,2,5,4,8,3,7]` 得 8，最优 49 |
| 3 | 对固定的 r，左端点取**最小的合法 l**，而且这个 l 只增不减 | 一冲突就重置 `l = r`：`"abcbde"` 得 3，最优 4（`"cbde"`） |
| 300 | 长度相同的上升子序列，**结尾越小越好**（后面能接的只多不少） | 把 replace 当 skip、只收 append 的：`[5,6,1,2,3]` 得 2，最优 3 |
| 122 | 任何一笔买卖的收益 = 区间内逐日差之和，所以「吃所有上坡」不比任何方案差 | 只做一笔（121 的解）：`[1,5,3,6]` 得 5，最优 7 |
| 853 | 后车的**到达时间** ≤ 前面车队的，就一定被堵住、并入 | 比速度：`target=10, pos=[0,9], speed=[2,1]` 得 1 队，实际 2 队 |
| 621 | 最多的任务搭骨架，长度 `max((max_cnt-1)*(n+1) + num_max, len(tasks))` | 尾巴写 `+1`：`AAABBB, n=2` 得 7，实际 8 |

右列每个反例都是跑出来的。3 和 300 那两行是自己真走过的弯路：3 的重置是「把串切成若干段各自无重复」的
分段心智，但答案可以横跨切的那一刀；300 是以为 tails 只在 append 时才「收」元素。

## 2. 三种证法

### 交换论证：把最优解的第一步换成我的

模板：取**任意**一个最优解 OPT，找到它和贪心第一处不同的那一步，把那一步换成贪心的选择，
证明换完 ① 仍然合法 ② 不变差。于是「选贪心那个」不会错过最优解，剩下的是同一问题的子问题，归纳到底。

完整的样板是 435，见 [intervals.md](intervals.md) §2（活动选择，CLRS 贪心那章的第一个例子）。
那里还说明了为什么**排序键是证明的一部分**：换成按 start 或按长度排，交换那一步就不成立了，
所以换键是算错，不是变慢。

300 的 tails 也是这个形状：两个长度都是 k 的上升子序列，结尾 `a < b`，任何能接在 `b` 后面的数都能接在 `a` 后面
—— 拿 `a` 换掉 `b` 不会更差。所以 `tails[i] = x` 是「换小」，不是「跳过」。

### 支配论证：被丢掉的候选，上限已经结算过了

模板：每一步丢掉一个候选，并证明**它能达到的最好值已经算进 `best` 了**。

- **11**：矮的那根当墙，高度被它自己封顶，宽度也只会变窄 —— 两个维度都涨不上去，丢掉它安全。
  这也是为什么必须**先结算再挪指针**，反了就漏掉这一对。完整论证见 [two-pointer.md](two-pointer.md) §2。
- **121**：比当前最低价高的历史价格，对**任何**未来的卖出日都更差，永久出局，留一个 `cur_min` 就够。
- **3**：r 固定时窗口越长越好，所以 l 能不动就不动；而「无重复」向下封闭（合法窗口的子串也合法），
  所以 r 右移时最小合法 l 不会往回退。这条单调性才是 O(n) 的来源。

### 界 + 构造：先证没人能更好，再证我达到了

模板：先给出一个**任何方案都越不过去的界**，再说明贪心恰好取到这个界。不需要和某个 OPT 比，
只需要和界比。

**122** 的上界：一笔「第 i 天买、第 j 天卖」的收益是

```
prices[j] - prices[i] = (p[i+1]-p[i]) + (p[i+2]-p[i+1]) + ... + (p[j]-p[j-1])
```

每笔交易只能吃到自己区间里的逐日差，负的也得吞下去；所以任何方案的总收益 ≤ 所有正的逐日差之和。
贪心（`prices[i-1] < prices[i]` 就加上差）正好把正的全吃了、负的全跳过，取到了这个界。

**621** 的下界有两个：最多的任务出现 `max_cnt` 次，两次之间至少隔 `n` 格，前 `max_cnt-1` 次各占一个长 `n+1` 的块，
最后一块只站着并列最多的那 `num_max` 种；另外总长不可能少于任务数。按骨架往块里填其余任务就能取到这个界，
块塞满了就没有空闲，长度就是 `len(tasks)`：

```python
class Solution:
    def leastInterval(self, tasks: List[str], n: int) -> int:
        cnt = Counter(tasks)
        max_cnt = max(cnt.values())
        # 尾巴上站着的只有并列最多的那几种
        num_max = sum(1 for v in cnt.values() if v == max_cnt)
        # 第一项：骨架下界；第二项：块塞满后无空闲，长度就是任务数
        return max((max_cnt - 1) * (n + 1) + num_max, len(tasks))
```

推不出公式时的退路是 heap 模拟（heap 存可发射的任务、deque 存冷却中的），见
[621 的 note](https://github.com/scatyf3/leetcode/blob/main/tracker/621.%20Task%20Scheduler/note.md)。

## 3. 证不出来：拿暴力去打它

那句话写出来了、证明卡住时，**写一个指数级暴力，在小数据上对拍**。这是「能证伪」的字面意思。

1405 就是这种题：「每步放剩余最多的字母；会造成三连就放第二多的；两个都放不了就停」。
证明不好写，但暴力很好写 —— 回溯所有合法串取最长：

```python
class Solution:
    def longestDiverseString(self, a: int, b: int, c: int) -> str:
        cnt = [[a, 'a'], [b, 'b'], [c, 'c']]
        res = []
        while True:
            cnt.sort(reverse=True)                 # cnt[0] 最多，cnt[1] 第二多
            for k in range(2):                     # 先试最多的，不行再试第二多的
                n, ch = cnt[k]
                if n > 0 and res[-2:] != [ch, ch]: # 放 ch 会不会造成三连？
                    res.append(ch)
                    cnt[k][0] -= 1
                    break
            else:                                  # 两个都放不了 → 结束
                return "".join(res)
```

```python
def brute(a, b, c):
    def dfs(cnt, last2):
        best = 0
        for i, ch in enumerate('abc'):
            if cnt[i] > 0 and last2 != ch * 2:
                cnt[i] -= 1
                best = max(best, 1 + dfs(cnt, (last2 + ch)[-2:]))
                cnt[i] += 1
        return best
    return dfs([a, b, c], '')
```

`a, b, c ∈ [0, 6]` 全部 343 组：贪心的长度和暴力一致，输出也都没有三连。没有证明，但比「感觉对」硬得多。
反过来，第 1 节右列的每个反例都是这么打出来的。

## 4. 坑

- **端点相碰**（435）：不重叠的判断是 `s >= end`，不是 `>`。同一个「相碰」在 56 / 452 里结论相反，见
  [intervals.md](intervals.md) §4
- **先结算再挪**（11）：丢掉短板之前先把这一对的面积记进 `best`
- **尾巴是 `+ num_max`**（621）：并列最多的几种都站在最后一块；而且要和 `len(tasks)` 取 max，块塞满时没有空闲
- **比到达时间，不是速度**（853）：`t == cur` 算追上，终点相遇也是同一队
- **tails 不是一条真实的子序列**（300）：长度可信，内容不可信
- **把 DP 当贪心**（152）：只留两个标量、一趟扫完，但 `mn` 现在最差、乘个负数就翻身，没有候选被永久排除 ——
  是汇总不是排除，见 [1d-dp.md](1d-dp.md) §4
