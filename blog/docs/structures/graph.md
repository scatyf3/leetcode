# 图

**图 = 一堆点 + 「谁能直接到谁」（边）。** 它维护的信息只有这一种：谁和谁直接相连。
链表是每个点只有一条出边的图，树是没有环、每个点只有一个父亲的图。把这两条限制去掉，多出来的麻烦主要是一个：**会绕回来**。
所以图上的遍历都要带一个 `visited`，而树上的 DFS 不用（[dfs.md](../paradigms/dfs.md)）。

```
链表   0 → 1 → 2              每个点一条出边

树       0                    没有环，每个点一个父亲
        / \
       1   2

图     0 ──→ 1      3         可能有环（0→1→2→0），也可能不连通（3）
       ↑   ↙
       2
```

怎么遍历见 [DFS](../paradigms/dfs.md) / [BFS](../paradigms/bfs.md)，这页讲图本身：怎么给的、怎么存、visited 记什么。

## 1. 图是怎么给你的

| 形式 | 要做什么 | 题 |
|---|---|---|
| 已经是节点对象 | 不用建，顺着 `neighbors` 走 | 133 |
| 隐式网格 | 不用建，邻居用方向数组现算 | 200、417（[grid.md](grid.md)） |
| 边列表 | **自己建邻接表** | 207 |
| 完全隐式，节点是「状态」 | 自己定义点和边 | 139：节点是字符串里的「缝」`0..n`，`s[i:j]` 在字典里就连一条 `i → j` |

越往下越难，难点从「怎么遍历」变成「**怎么建模**」（207 的 note）。
认出隐式图的信号：题目给了**一步**的规则，却问**多步**的结果（417 的 note）。

## 2. 邻接表

边列表的建法是固定的：

```python
graph = [[] for _ in range(n)]
for a, b in edges:
    graph[a].append(b)
    graph[b].append(a)   # 无向图才加这行
```

**先想清楚边的方向。** 207 的 `[a, b]` 意思是「修 a 之前要先修 b」，所以边是 `b → a`（修完 b 解锁 a），`indeg[a] += 1`。
sol.py 里前两个坑就是「谁指向谁」和「谁的入度 +1」。

207 还要一个入度数组：`graph[u]` 记 u 的出边列表，`indeg[v]` 记有几条边指向 v。
入度就是「入边列表**压缩成长度**」（207 的 technique）：Kahn 只关心还差几个前置，不关心差的是谁，见 [bfs.md](../paradigms/bfs.md) §6。

## 3. visited 记什么

| 要回答的问题 | 用什么 | 题 |
|---|---|---|
| 来过没有 | `set`，或者原地改 grid | 200、417 |
| 来过没有 + 对应的克隆是谁 | `dict`：`old → new`，有 key 就是来过 | 133 |
| 来过没有 + 是不是还在当前路径上 | 每个点三种状态 | 有向图判环（207 的 DFS 写法） |

> `set` 回答「有没有」，`dict` 回答「有没有 + 是什么」（133 的 note）。

### 有向图判环为什么要三种状态

普通 visited 只分「来过 / 没来过」。但有向图里**来过 ≠ 有环**：

```
0 → 1 → 2
└───────↗
```

从 0 出发先走 `0→1→2`，2 搜完；回到 0 再走 `0→2`，又碰到 2 —— 来过，但没有环。所以「来过」要拆成两种：

- **在当前路径上**（还在递归栈里）：又碰到它 = 绕回来了 → **有环**
- **已经搜完**：这条路之前验证过 → 直接跳过

133 的 DFS 里其实也有这三种状态（白：没碰过；灰：克隆已经建了，`neighbors` 还没填完；黑：填完了）。
但 133 只要克隆、不判环，碰到灰的直接把克隆拿来用就行，所以一个 `dict` 就够。

## 4. 从哪开始搜

| 起点 | 题 |
|---|---|
| 题目给了 | 133（给的那个 `node`） |
| 满足条件的点一起入队（多源） | 207 入度为 0、994 烂橘子、417 海边一圈 |
| 外层循环所有点，没访问过就搜一次 | 200 —— 图可能不连通，搜了几次就有几块 |

## 5. 有环就不能 DP

DP 要求依赖无环，能排出「先算谁」的顺序。139 的边只往右（`i → i + len(word)`），是 DAG，所以能 DP；
用搜索写时，visited 只是为了不重复展开同一个切点，不是防环（139 sol1 的注释）。
417 的水能往四个方向流，依赖成环，排不出扫描顺序，只能搜索。详见 [1d-dp.md](../paradigms/1d-dp.md) §7。
