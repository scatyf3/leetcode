# 数组

数组的能力：**随机访问 O(1)、有下标顺序**。大多数技巧都是在利用「下标」和「顺序」做文章。
这一页只讲数组自己的东西：下标怎么记、两个原地操作、拿到数组题先问什么。
具体的解题套路（双指针、滑窗、前缀和、DP）各有各的页面，见最后一节。

二维数组多出「行列对称性、邻接关系、层/圈结构」三样东西，单独一篇：[matrix.md](matrix.md)。

## 约定

### 缝：下标指元素，还是指元素之间

下标可以指**元素**，也可以指元素之间的**缝**(gap)。n 个元素有 n+1 条缝，编号 `0..n`：

```
gap   0   1   2   3   4
      |   |   |   |   |
      | a | b | c | d |
idx     0   1   2   3
```

缝 `i` 卡在 `a[i-1]` 和 `a[i]` 中间。`len(lst)` 不是合法的元素下标，但它是最后那条缝，实实在在存在。

> 自检一句话：**元素 n 个，缝 n+1 条。** 表开 `n` 还是 `n+1`、二分右端取 `n-1` 还是 `n`、
> 前缀和要不要写 `P[i+1]`，全是这一条在起作用。off-by-one 多半是两套编号混着用了。

Python 的切片 `a[l:r]` 和 `range(l, r)` 是**左闭右开** `[l, r)`：`l`、`r` 都是缝，含头不含尾。
半开是默认，但不是每道题都该用它。判据只看**右端点是怎么来的**：

> **右端点是一个真实的、要被处理的元素 → 闭 `[l, r]`；右端点是你放的一道边界（一条缝） → 半开 `[l, r)`。**

| 右端点 | 它是什么 | 记法 | 题 |
|---|---|---|---|
| 切片、`range` | 缝。长度直接 `r - l` | 半开 | 到处都是 |
| 前缀和 `P[i] = sum(a[0..i))` | 缝。所以表开 n+1 长，`sum(l, r) = P[r] - P[l]` | 半开 | 238、560 |
| 二分找插入位 | 缝。插入点可能在末尾之后，所以 `r = n` | 半开 | 35 |
| 「在哪切一刀」 | 缝。节点是 n+1 条缝，不是 n 个字符 | 半开 | 139 |
| 递归切数组 | 缝。`[l, m)` 和 `[m, r)` 正好拼成 `[l, r)`，中点不用想 ±1 | 半开 | 105、297（返回「吃完之后的第一格」） |
| 读写指针 `w` | 缝：下一个要写的位置（见下一节） | 半开 | 26、27 |
| 滑窗的 `r` | 元素：`for` 刚吃进来的那个 | 闭 | 3、424、76 |
| 相向双指针 | 元素：两头每轮都要读 `a[l]`、`a[r]` | 闭（`while l < r`） | 11、15、167、125 |
| 二分闭区间模板 | 元素：还可能是答案的候选 | 闭（`while l <= r`） | 704、35 |
| 题目接口给的 `[left, right]` | 题面规定包含两端 | 闭，**进门就转成半开** | 303 `sumRange(left, right)` 算成 `P[right + 1] - P[left]` |

两套里的 ±1 总数是一样的，选哪套只决定它们出现在哪：闭区间的 ±1 在长度公式（`r - l + 1`），
半开的 ±1 在元素访问（`a[r - 1]`）。哪个在这道题里写得少，就选让它少的那套。
滑窗页有一个完整的例子：[paradigms/sliding-window.md](../paradigms/sliding-window.md)「为什么滑窗写闭区间」。

**一道题里只用一套，在函数入口就定下来，写在注释里**（`# 都是左闭右开`）。

同一套约定在二维上的版本见 [matrix.md](matrix.md) §0；二分的两套模板见 [paradigms/binary-search.md](../paradigms/binary-search.md)。

### 读写指针

类似in place sort，或者把不符合的swap到后面的invalid段类。一个 `w`(写/慢) 一个 `r`(读/快)，
`r` 逐格扫过全部元素，`w` 指向**下一个要写的位置**，不变式把数组切成三段：

```
    0            w          r            n
    [--- kept ---|-- junk --|-- unread --]
```

`kept` 已保留(就是结果)、`junk` 已丢弃的垃圾(可以随便踩)、`unread` 还没读到的。

`w` 是一条缝，**三重身份**同时成立：下一个写入位 / 已保留的个数 /
要返回的值 —— 所以 LC 26、LC 27 直接 `return w`，不用另开计数变量。

**为什么原地覆盖是安全的**：`w <= r` 恒成立，要踩的格子早被 `r` 读过了。这条一旦不成立
就得掉头 —— LC 88 合并两个有序数组时从前往后写会覆盖 `nums1` 里还没读的数据，所以改成
**从后往前填**。

两种写法，选一种记死：

| 写法 | 保序 | 搬运次数 | 适合 | 题 |
|---|---|---|---|---|
| **覆盖式** `if keep(a[r]): a[w] = a[r]; w += 1` | ✓ | 保留几个搬几次 | 要保留的多 | LC 26 / 27 |
| **交换式** 把要删的和末尾 swap，`n -= 1` | ✗ | 删几个搬几次 | 要删的极少 | LC 27 第二解 |

完整 SOP(不变式怎么写、约定 A/B 的差别、返回 `w` 还是 `w+1`)见
[notes/two-pointer-array-partition.md](https://github.com/scatyf3/leetcode/blob/main/tracker/notes/two-pointer-array-partition.md)；
它在范式上属于双指针的「同向·快慢」一族，见 [paradigms/two-pointer.md](../paradigms/two-pointer.md) §2。

### 反转

1. naive的解是rotate k，然而需要extra space
2. 优化的方法是：`rev(AB): rev(A),rev(B),rev(total)`

eg: 
```
        [1 2 3 4 5 6 7]    n = 7, k = 3
         └──A──┘ └─B─┘     手上是 AB, 要的是 BA

(1)     [7 6 5 4 3 2 1]    反转全部    rev(AB) = B'A'  两段位置对了, 但各自是倒的
         └─B'┘ └──A'─┘
(2)     [5 6 7 4 3 2 1]    反转前 k    B' → B
         └─B─┘
(3)     [5 6 7 1 2 3 4]    反转后 n-k  A' → A          ✓
               └──A──┘
```

- 右旋 k 位：反转全部 → 反转前 k → 反转后 n-k（LC 189 Rotate Array）
  - 坑：`k` 可能大于 `n`，第一件事是 `k %= n`；`k == 0` 时三次反转恰好还原，不用特判
- O(1) 空间的「段交换」原语，字符串旋转、翻转单词同理。

同一个原语升到二维就是「转置 + 反转 = 旋转」，见 [matrix.md](matrix.md) §3 —— LC 48 Rotate Image 就是它。

## 拿到数组题先问的四个问题

读题时这四个问题各自能直接拍板一个方向，其余的（有没有重复、返回 value 还是 index）读题时自然就看到了。

| 问题 | 答案 → 方向 | 题 |
|---|---|---|
| **有序吗？** | 有序 → 二分、相向夹逼、归并。部分有序（rotate 过）→ 找仍然单调的那一半。无序 → **先问能不能排序**：要返回原下标就不能排（LC 1 只能哈希；同题给有序数组的 167 就能夹逼） | 35、704、167、88、33、153、15、56 |
| **值域多大？** | 小且连续 → 直接开数组当桶（26 个字母、频次 ≤ n）。值域 = 下标域还要 O(1) 空间 → 原地哈希。都不是 → 老实用 `dict` | 242、424、347、41 → [hash-table.md](hash-table.md) §2 / §8 |
| **要求原地吗？** | 读写指针（上面）、从后往前填（88）、三次反转（189）、原地哈希（41） | 26、27、88、189、41 |
| **要的是连续的一段吗？** | 连续 → 滑窗、前缀和、Kadane。能不能滑窗看统计量撤不撤得掉：有 0 的乘积撤不掉（152），有负数前缀和不单调（53）。不要求连续 = 子序列，多半是 DP | 3、424、560、53、152、300 → [notes/subseq-vs-substr.md](https://github.com/scatyf3/leetcode/blob/main/tracker/notes/subseq-vs-substr.md) |

## 和其他结构的联系

1. **语义替代**: hash，array可以做一个天然的以[0..n]的正int为key的hash（反过来「什么时候必须是真哈希表」见 [hash-table.md](hash-table.md)）
   - 值域小且连续 → 直接开桶(LC 242 26 字母、LC 424 窗口频次、LC 169 计数)
   - 把值当下标反着存(LC 347 下标=频次，O(n) 干掉堆的 O(n log k))
   - 值域大或不连续 → 才退回 dict(LC 1 值→下标、LC 128 用 set、LC 3 char→上次出现位置)
2. 可以拿来做别的结构的**building blocks**
   - 二叉树：LC 297 tree → array；LC 105 从两个数组重建树，**array 的一段切片就是一棵子树**
   - heap：完全二叉树的下标公式 `2i+1` / `2i+2`，heapq 底下就是个 list
   - matrix：array 套 array（LC 54、48、36）
   - string：本质上是不可变的 array，滑窗、双指针技巧照搬，只是要先 `list()` 才能改
   - graph：邻接表 = array 套 array；网格本身就是隐式图（LC 417）
   - bitmap：拿 int 当定长布尔数组（LC 190、191、338）
