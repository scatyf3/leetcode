# 二进制位

一个 int 就是一排开关：第 i 位是 0 还是 1，就是第 i 个布尔值。所以 int 能当一个**定长的布尔数组**（bitmap）用，
读写某一位 O(1)，两排开关一起 `&` `|` `^` 也是一条指令。要背的那几个技巧在 [位运算](../paradigms/bit-manipulation.md)，这里只讲这个「数组」本身。

```
n = 11 = 0b1011
位号:  3 2 1 0
       1 0 1 1      → 第 0、1、3 位是 1，当集合看就是 {0, 1, 3}
```

## 读写第 i 位

| 操作 | 写法 | 十进制的对应 |
|---|---|---|
| 最低位 | `n & 1` | `n % 10` |
| 去掉最低位 | `n >> 1` | `n // 10` |
| 读第 i 位 | `(n >> i) & 1` | |
| 第 i 位置 1 / 清 0 / 翻转 | `n \| (1 << i)` / `n & ~(1 << i)` / `n ^ (1 << i)` | |

右边那一列不是凑数：190 逐位翻转 `res = (res << 1) | (n & 1); n >>= 1` 和十进制翻转 `res = res * 10 + n % 10; n //= 10` 是同一个骨架。

## 当集合用：mask

元素不超过 20 个左右时，一个子集就是一个 int，第 i 位为 1 表示选了第 i 个。全部子集就是 `range(1 << n)`，2^20 ≈ 10^6 还枚举得动。
78 Subsets 仓库里是回溯写的，换成 mask 是这样：

```python
def subsets(nums):
    n = len(nums)
    res = []
    for mask in range(1 << n):
        res.append([nums[i] for i in range(n) if (mask >> i) & 1])
    return res
```

## 位宽：Python 的 int 没有，要自己给

C / Java 的 int 是 32 位，Python 的 int 是无界的，**「这个数有几位」是题目给的，不是 int 自带的**。

- **190**：前导零也是有效位。`n = 1` 是 `000…001`，反转后是 `100…000 = 2**31`，不是 1。所以固定跑 32 轮、
  或者 `f"{n:032b}"` 补零，不能用 `while n:` 也不能用 `len(bin(n))`。
- **191** 反而不用补：前导零不贡献 1，补不补结果一样。要不要位宽，看「零位算不算数」。
- **负数**：按位运算时 Python 把负数当成「左边有无限多个 1」的补码，所以 `-1 & 0xFF == 255`、`-5 >> 1 == -3`（算术右移，向下取整），
  `-1 >> 1` 还是 `-1`，对负数写 `while n: n >>= 1` 停不下来。但 `bin(-5)` 打印的是 `'-0b101'`（符号 + 绝对值），不是补码。
  要模拟 32 位就自己截：`x & 0xFFFFFFFF` 得到无符号的 32 位，转回有符号是 `x - (1 << 32) if x >> 31 else x`。
  371 Sum of Two Integers 就得这么写（仓库里还没做）。

## int 和二进制串互转

| 写法 | 结果 |
|---|---|
| `f"{n:b}"` / `bin(n)` | `'1011'` / `'0b1011'`（`bin` 带前缀） |
| `f"{n:032b}"` | 补零到 32 位。`0` 是用零填充，`32` 是宽度，`b` 是二进制；宽度可以嵌套 `f"{n:0{BITS}b}"` |
| `int(s, 2)` | 串转回 int |
| `n.bit_length()` | 最高位的 1 在第几位 + 1（`0` 是 0） |
| `n.bit_count()` | 1 的个数，3.10+；老版本 `bin(n).count('1')` |
