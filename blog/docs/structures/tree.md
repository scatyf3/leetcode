# 树

## 一句话

链表的每个节点只记「下一个是谁」，树的节点记「**孩子们是谁**」。多了这层父子关系，
一个问题就能拆成「我自己 + 我的几棵子树」，所以树题几乎都是递归。怎么递归见 [DFS](../paradigms/dfs.md)，按层走见 [BFS](../paradigms/bfs.md)。

## 长什么样

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

**空树就是 `None`**，而且它是递归最好用的 base case：`if node is None: return ...` 一行就把叶子、
只有一边孩子的节点这些情况全吸收了，不用再单独判断（94、100）。

## 容易记混的定义

| 概念 | 定义 | 坑 |
|---|---|---|
| 深度 / 高度 | 104 数的是**节点数**：只有根的树深度为 1 | 543 直径数的是**边数**。[DFS](../paradigms/dfs.md) §1 里 543 的写法让递归返回节点数，`l + r` 恰好是边数，两套口径在同一行里对上 |
| 平衡 | **每个节点**的左右子树高度差不超过 1 | 不是只看根；110 第一遍理解错了定义 |
| BST | 每个节点比左子树里**所有**节点大、比右子树里**所有**节点小 | 只和父节点比是错的，要沿路径传上下界（98）。等价说法：中序遍历严格递增 |
| 完全二叉树 | 除最后一层外全满，最后一层靠左 | 能直接存进数组：下标 i 的孩子在 `2i+1` / `2i+2`，堆就是这么存的（[heap.md](heap.md)） |

## 遍历顺序决定能保留什么

| 顺序 | 访问次序 | 能拿来干什么 |
|---|---|---|
| 前序 | 根 → 左 → 右 | 第一个就是根。加上空节点占位 `#`，可以**唯一还原**整棵树（297） |
| 中序 | 左 → 根 → 右 | BST 上 = 升序（94、230）。但加了 `#` 也**还原不出来**：不同的树能写出同一个中序串 |
| 后序 | 左 → 右 → 根 | 最后一个是根 |
| 层序 | 一层一层 | 用 BFS 写（102、199）；也能加占位唯一还原 |

**前序 + 中序**（值不重复）也能唯一还原：前序告诉你根是谁，中序告诉你左右子树各有几个节点（105）。

## 树和其他结构互相转换

| 转换 | 怎么做 | 题 |
|---|---|---|
| 有序数组 → BST | 中点当根，左右两半递归，自动平衡 | 108 |
| 树 → 链表 | 按前序把节点串到 `right` 上，`left` 全部置空 | 114 |
| 树 → 字符串 | 前序 + `#` 占位 + 分隔符 | 297、572 |
| 子树关系 → 子串关系 | 两棵树都序列化，问「是不是子树」变成问「是不是子串」 | 572 |

572 用序列化时，**分隔符和 `#` 占位缺一不可**：不加分隔符，`12` 和 `1`、`2` 写出来一样；
不加占位，形状不同的树也能写出同一个串。

## 多叉树

二叉树是孩子最多两个的特例。孩子数不固定时，`left` / `right` 换成一个 `children` 列表或字典就行，
递归写法不变，只是两次递归换成一个 `for` 循环。[Trie](trie.md) 就是一棵按字符分叉的多叉树。
