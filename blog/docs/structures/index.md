# 概念数据结构

<StructureMap />

最底下两种决定**数据在内存里怎么放**，再往上每一种都是在它们上面**多维护了一种信息**：

| 结构 | 多维护的信息 | 换来什么 | 实现 |
|---|---|---|---|
| 数组 / 链表 | —— | 数组随机访问 O(1)；链表任意位置插删 O(1)（手里已经有节点的话） | 连续内存 / 节点 + 指针 |
| 栈 / 队列 | **插入时间** | 最晚 / 最早进来的那个 O(1) 取 | 数组 + 下标；队列用环形缓冲或链表 |
| 哈希集合 / 哈希表 | **唯一性**（只问相等不相等） | 按 key 查 O(1) 均摊 | 哈希函数 + 数组（拉链或开放寻址） |
| 堆 | **值本身，但只保偏序** | 最值 O(1)，插入 / 弹出 O(log n) | 数组当完全二叉树 |
| 有序集合 | **全序** | 任意值查找 / 前驱后继 O(log n) | 平衡 BST |

从堆到有序集合是「偏序 → 全序」：堆只保证父比子小，所以只能 O(1) 拿最值；
有序集合把所有元素排好，所以能问「比 x 大的最小那个」。代价是常数大、Python 里还没有内置。
