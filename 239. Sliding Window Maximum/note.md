这里和单调栈的区别是？

队尾那一侧的操作一模一样（新元素进来，弹掉被它支配的），真正的区别是：

| | 单调栈 | 单调队列 |
|---|---|---|
| 从哪端出元素 | 只从一端 | 两端：队尾踢被支配的，队首踢过期的 |
| 答案在哪产生 | **弹出的那一刻**：谁把 j 弹出去，谁就是 j 的「下一个更大」 | **看队首**：弹掉的元素直接丢弃，答案是留下来的那个 |
| 答的是什么问题 | 每个元素和邻居的关系（739 下一个更暖的天、84 左右第一个更矮的柱子） | 每个窗口的最值（239） |
| 元素怎么离开 | 只有一种：被支配 | 两种：被支配，或者滑出窗口 |

> 单调栈的答案在**被弹出的元素**身上，单调队列的答案在**留下来的队首**身上。
>
> 问「每个元素往右 / 往左第一个比它大 / 小的是谁」→ 单调栈；问「每个长度为 k 的窗口里的最值」→ 单调队列。

### pass2 卡在哪

填空时栽的地方，下次空白重写重点盯这几处：

| 位置 | 写错成 | 应该是 |
|---|---|---|
| 存什么 | 一会儿存值、一会儿当下标用 | 定死存下标，比较一律 `nums[dq[...]]` |
| 单调方向 | 队首到队尾递增 | **递减**，队首 = 最大 |
| 队首过期 | `dq[0] < i` | `dq[0] <= i - k`（窗口是 `[i-k+1, i]`，`i-k` 刚滑出去） |
| 窗口满没满 | 看 dq 里的下标差 | 看 `i >= k - 1`，和 dq 无关 |
| 取答案 | `dq[-1]` | `nums[dq[0]]` |

> 队首「最大、最老」，队尾「最新、最小」；窗口满没满看 `i`，最大值取 `nums[dq[0]]`。
