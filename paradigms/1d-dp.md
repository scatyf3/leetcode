# 1d DP 通用 trick

**信号**：题目给了「**一步**的规则」，却问「**多步**的结果」，而且候选**丢不掉**。

丢得掉就不是 DP：
1. 能证明「某个候选永远不可能更优」→ 双指针/贪心（见[paradigms/two-pointer.md](two-pointer.md)）；
2. 证不出来 → 只能留着汇总 → DP。
152 就是证不出来的典型：`mn` 现在最差，乘个负数就翻身。这里是dp因为决策方式没退化，虽然空间退化成了O(1)

## 1. 三个填空位

写 1d DP 只有三件事，缺一个就写不出来：

| 填空位 | 要回答 | 典型错法 |
|--------|--------|---------|
| **状态定义** | `dp[i]` 到底是什么的最优值 | 口径含糊 → 转移写不出来 |
| **转移方程** | `dp[i]` 由哪些更小的 `dp` 决定 | 依赖成环 → 根本不是 DP |
| **base + 方向** | 从哪开始、往哪扫 | 初始化漏项、方向反了 |

## 2. 状态定义的两种口径（1d DP 最大的坑）

```
A. dp[i] = 以 i 结尾 的最优        → 答案 = max(dp)，不是 dp[n-1]
B. dp[i] = 前 i 个   的最优        → 答案 = dp[n]
```

**什么时候必须用 A？转移需要「接在前一个后面」这个语义时。** 类似1d里连续的切片而不是离散的切片

152 乘积最大子数组：如果定义成「前 i 个里的最大乘积」，你根本没法递推——
因为不知道那个最优子数组是不是以 `i-1` 结尾，接不上去。改成「以 i 结尾」，
`dp[i]` 和 `dp[i-1]` 之间才有物理连接。代价是答案得再扫一遍取 max。

- **A 类**：152 乘积最大子数组、53 最大子数组和、最长上升子序列
- **B 类**：70 爬楼梯、139 单词拆分、打家劫舍

> 判据：**子结构是「连续的一段」→ 用 A；是「一个前缀」→ 用 B。**

## 3. 状态可以是「一维下标 + 常数个分量」

**「一维 / 二维 DP」里的「维」指的是下标的维数，不是每格存几个数。**

`dp[i]` 里可以装一个元组。下面两种写法完全等价，都还是 1d：

```python
dp[i] = (mx_i, mn_i)      # 一个数组, 每格存一对
f[i], g[i] = mx_i, mn_i   # 两个平行数组
```

搞混的代价是实打实的：

| | 状态个数 | 复杂度 |
|---|---|---|
| 一维下标 + k 个分量（k 常数） | `n × k` | **O(n)** |
| 二维下标（区间 DP、背包） | `n × n` | **O(n²)** |

把「要存两个数」误当成「要开二维数组」，就会白花 `n²` 的空间做一件 O(n) 的事。

### 什么时候需要多个分量

当**「哪个候选最优」取决于还没看到的信息**时，就不能只留一个：

| 题 | 分量 | 为什么留不住一个 |
|----|------|----------------|
| 152 乘积最大 | `(最大, 最小)` | 负数翻转顺序，最小值随时变最大值 |
| 打家劫舍 198 | `(偷 i, 不偷 i)` | 这间偷了下一间就不能偷 |
| 买卖股票通用型 | `(持股, 空仓)` | 能不能卖取决于手上有没有货 |

共同点：**「身份」会影响下一步能做什么**，所以状态里必须带上身份，不能只带数值。

- **152**：每格存 `(mx, mn)` 两个数——因为负数会让最小值翻身成最大值

  ```python
  cand = (x, mx * x, mn * x)          # 三个候选
  mx, mn = max(cand), min(cand)       # 必须同时更新，不能先算 mx 再拿新 mx 算 mn
  ```

  三个候选穷举了「以 i 结尾的子数组」的全部来源：从 `x` 重新起头 / 接在最大后面 / 接在最小后面。
  写成两行的话，第二行会拿**刚算出来的新 `mx`** 去算 `mn`，而转移要求两个都用旧值——本题最经典的 bug。

- **买卖股票系列**：每格存「持股 / 空仓」→ 状态机 DP。121（只能买卖一次）退化成一个
  `min_so_far` 标量，122（无限次）连状态都不用记 —— **它俩不是另一类题，是同一个状态机被
  约束压扁后的特例**。做到 123（最多两次）/ 309（含冷冻期）时完整形态才露出来。
- **打家劫舍 198**：每格存「偷 / 不偷」（这题还没做，是「带身份的状态」最干净的样本）

> 看到「有两种互斥情形会互相转化」就往这上面想，别急着开二维数组。

## 4. 贪心 = 退化的 DP

退化条件：**每步的赢家当场唯一确定**，不需要留候选。

| 题 | 需要留什么 | 结论 |
|----|-----------|------|
| 121 买卖股票 | 一个标量（左边最小值） | 退化 DP ≈ 贪心 |
| 122 买卖股票 II | 什么都不用留（只看相邻两天） | 纯贪心 |
| 152 乘积最大 | 两个标量，且会互相翻转 | 真 DP |

「只依赖前 k 步」决定的是**能不能压缩空间**，和贪心/DP 无关——这条见
[structures/array.md](../structures/array.md) §5。

### 152 只留两个标量、一趟扫完，凭什么不算贪心？

因为它**什么都没丢**。贪心是排除法，152 是汇总法。

`nums = [-2, 3, -4]`：

| i | x | 候选 | mx | mn |
|---|---|------|----|----|
| 0 | -2 | — | **-2** | **-2** |
| 1 | 3 | `3, -6, -6` | **3** | **-6** |
| 2 | -4 | `-4, -12, 24` | **24** ← 来自 mn | -12 |

答案 24 由 `mn` 生出，而 `mn` 在第 1 步是全场最差的 `-6`。
**任何一步「贪心地」丢掉当前最差的候选，答案就没了** —— 不存在能证明某候选出局的那一刻。

**那为什么两个极值就够？** 乘一个固定的 `x` 是**单调映射**（`x>0` 保序，`x<0` 逆序），
单调映射把集合的 max/min 映射成像集合的 max/min。所以「所有以 i−1 结尾的乘积」这个集合，
对未来有用的信息恰好就是它的最大和最小 —— `(mx, mn)` 是它的**充分统计量**。

> 这不是「我挑了两个值来贪」，是「我把整个候选集合无损压缩成了两个数」。**汇总，不是排除。**
> 若转移不是单调映射（比如 `y ↦ y² − k`），两个极值立刻不够用 —— 这个模板是针对乘法算出来的，不普适。

对照 121：比当前最小值更高的历史价格，对**任何**未来卖出日都更差 → 真的被永久排除了 → 那才是贪心。

**判据一句话：有没有哪个候选被永久排除？有 → 贪心；没有，只是把候选集压缩了 → DP。**

## 5. 滚动压缩：数组退化成若干标量

**判据只有一条：把转移方程右边出现的所有下标圈出来，算 `max(i − 那些下标)`。
这个「依赖窗口宽度」是常数 k，就只需要 k 个标量；不是常数，就必须留数组。**

注意压缩只改空间、不改时间。O(n) 还是 O(n)，但面试里几乎必问。

### 机械流程

```
① 写出转移方程，圈出右边所有的 dp 下标
② k = max(i − 被依赖的下标)          ← 依赖窗口宽度
③ k 是常数 → 开 k 个标量，用语义命名（prev / prev2 / min_so_far）
④ 循环体内：先用旧值算出全部新值，再整体移位   ← 顺序反了就错
⑤ 答案若是 max(dp)，加一个 best 边滚边记        ← 数组没了，最后没法再扫
```

### 你的题按这条判据分类

| 题 | 转移依赖 | k | 能压到 |
|----|---------|---|-------|
| 70 爬楼梯 | `dp[i-1], dp[i-2]` | 2 | 2 个标量 |
| 121 买卖股票 | `min(prices[0..i-1])` | 1 | 1 个标量 `min_so_far` |
| 152 乘积最大 | `mx[i-1], mn[i-1]` | 1（×2 分量） | 2 个标量 |
| 139 单词拆分 | `dp[j]`，`j` 落在最长词长 L 内 | L | L 个标量（常数但不划算，通常不压） |
| **338 比特位计数** | `dp[i>>1]` | **不是常数** | **压不掉** |
| **42 接雨水** | `L[i-1]` 和 `R[i+1]` | 各 1，但**方向相反** | 单靠滚动压不掉 |

```python
# 70：k = 2，所以两个标量
a, b = 1, 2
for _ in range(3, n + 1):
    a, b = b, a + b        # 同时更新：右边全是旧值
```

### 两个压不掉的典型（都是你做过的）

**338 是「跳跃依赖」不是「窗口依赖」**：`dp[i]` 要的是 `dp[i>>1]`，
而 `i>>1` 离 `i` 有多远取决于 `i` 本身（i=1024 时差了 512 格）。
圈下标算出来的 k 随 n 增长 ⇒ 整个数组都得留着。
**「只依赖一个前项」不等于「只依赖前一格」**——这是最容易看走眼的地方。

**42 是「两个方向撞在一起」**：`L[]` 要从左往右滚，`R[]` 要从右往左滚，
可每个位置的答案 `min(L[i], R[i]) − h[i]` 需要两者**同时在手**。
一个循环只能有一个方向，所以滚动压不掉——真要 O(1) 空间必须换范式，
改成相向双指针（见 [paradigms/two-pointer.md](two-pointer.md)）。
> 这条很重要：**压不动的时候，答案往往不是「优化 DP」，而是「换一个范式」。**

### 什么时候压缩本身就不该做

- **要输出方案不只是最优值** → 得回溯，路径信息在数组里，压了就没了
- **答案不是「最后一格」也不是「边滚边能记的量」**（比如要「第 k 大的 dp 值」）
- **调试阶段** → 留着数组能一眼看出哪一格开始错，压缩版只能看到最终结果

### 自检三问（来自 121 的复盘）

① 枚举哪个决策点？② 向哪一侧要信息？③ 能否让「枚举方向」=「依赖方向」？
能 → 那一侧的极值/累加值滚成一个标量。121 枚举卖出日、只向左要最小值，
两个方向一致，所以一个 `min_so_far` 就够。

## 6. 复杂度是从哪省出来的

338 的教训：**「存在闭式公式」和「能省时间」是两件事**。省时间只有两个来源——

| 来源 | 长什么样 |
|------|---------|
| 数学结构坍缩 | 等差求和 `n(n+1)/2`、快速幂 |
| **复用已算过的答案** | DP、前缀和、滑动窗口、单调栈 |

绝大多数题落在第二种。`dp[i] = dp[i>>1] + (i&1)` 就是「i 的二进制 = (i>>1) 再接一位」，
复用的是 `i>>1` 那个已经算好的答案。

## 7. 布尔 DP 可以退化成图上的可达性

`dp[i] = True/False` 且转移是「或」的时候，等价于「从起点能不能走到 i」。

139 单词拆分：节点是**缝**（`0..n` 共 n+1 个，不是字符），词的每次出现是一条边
`i → i+len(word)`，边只向右 ⇒ DAG ⇒ 可以 DP，也可以直接搜索。

**反过来，依赖一旦成环就只能搜索**：417 太平洋大西洋里水能四向流，
`(r,c)` 可能依赖 `(r,c+1)` 而后者又依赖它 ⇒ 排不出任何扫描顺序 ⇒ DP 死路。
破法见 [417 的 note](../417.%20Pacific%20Atlantic%20Water%20Flow/note.md)。

> **DP 成立的前提是依赖无环**。这一条比任何模板都重要。

## 8. 坑

- **base case 漏项**：70 里 `n==1/2` 要单独给，`dp` 数组长度别写成 `n` 又去访问 `dp[n]`
- **答案位置**：A 类口径的答案是 `max(dp)`，写成 `dp[-1]` 就错
- **同时更新**：多分量状态必须用旧值同时算出新值（152 的 `mx, mn = ...`）
- **空输入**：`nums` 为空时 `dp[0] = nums[0]` 直接炸
