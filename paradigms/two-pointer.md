# 双指针 通用 trick

**定义**：维护两个下标，每步用 O(1) 的局部信息决定「动哪个」，总步数 O(n)。
省掉的那层复杂度，来自**每步都能永久排除一批候选**——排除不掉就不是双指针，是暴力两层循环。

## 1. 分类轴：两个下标怎么动

先问一个问题：两个指针在**同一个序列**上，还是**各在一个序列**上？

### A. 各在一个序列上 → 归并型

两条已排序的东西，各出一个指针，比较后取小的推进。

| 题 | 变体 |
|----|------|
| 21 合并两链表 | 哨兵节点消灭空表特例 |
| 88 合并有序数组 | **从后往前**填，避免覆盖未读数据 |
| 23 合并 K 个链表 | k 条时指针换成堆，本质同一个东西 |

> 归并型没有「排除候选」这回事，它是**线性扫描的配对**，O(n) 来自「每个元素只被读一次」。
> 和下面三族的正确性论证完全不同，别混。

### B. 同一个序列上 → 三种运动方式

```
同向   l ──→   r ──→        快慢指针 / 滑动窗口
相向   l ──→ ←── r          左右夹逼
相背   ←── l  r ──→         中心扩展
```

| 运动 | 距离 `r−l` 的地位 | 正确性靠什么 | 你的题 |
|------|------------------|------------|--------|
| 同向·快慢 | 无意义（`l` 是写入位） | 慢指针 = 已处理个数，三重身份 | 26, 27, 141 |
| 同向·滑窗 | **就是答案**（窗口长度） | 合法性向下封闭 ⇒ `l` 单调不减 | 3 |
| 相向·夹逼 | 通常无关；11 是特例，当封顶量 | **支配论证**：丢掉的候选上限已结算 | 11, 15, 42 |
| 相背·扩散 | **就是答案**（回文长度） | 回文收缩封闭 ⇒ 沿对角线走到断为止 | 5, 647 |

**这张表就是「距离到底有没有意义」的答案**：距离是目标函数的只有滑窗和中心扩展；
夹逼里距离通常压根不出现，出现时（11）也只是**约束/封顶量**，不是目标。

## 2. 逐族的正确性论证

四族的 O(n) 来源互不相同，写题时要说得出自己在用哪一条。

### 相向·夹逼：支配论证

每步要能证明「**被移走的端点，其最优值已经结算完，不可能翻身**」。

- **11 盛水容器**：短板那侧，高度封顶（`min` 恒等于它）**且**宽度封顶（对面已是最远）
  → 两个维度都没救。缺任何一根柱子都丢不掉，`r−l` 单调递减正是第二根柱子。
- **15 3Sum**：靠**排序**。和偏小必须让某个数变大，有序保证 `l+1` 不更小。距离没参与。
- **42 接雨水**：靠 `Lmax/Rmax` 单调不减，谁小谁那侧的水位当场定死。距离没参与。

> 反过来说：**证不出「这个候选永远不可能更优」，就不能丢，只能留着 → 那是 DP 不是双指针。**
> 152 乘积最大子数组就是证不出来的例子（`mn` 现在最差，乘个负数就翻身），
> 所以它只能滚动 DP 汇总，不能双指针排除。详见 [152 的 note](../152.%20Maximum%20Product%20Subarray/note.md)。

### 同向·滑窗：合法性向下封闭

合法窗口的任意子串也合法 ⇒ 收缩一定安全 ⇒ `l` 全程只右移 n 步。
**回文不满足这条**（`"aba"` 是回文但 `"ab"` 不是），所以 5/647 套不上滑窗——
这条分水岭见 [notes/sliding-window-template.md](../notes/sliding-window-template.md)。

### 相背·扩散：收缩封闭

回文左右各缩一格仍是回文 ⇒ 可以从中心一路扩到断为止。
枚举对象是**中心不是端点**（`2n−1` 个中心，漏偶中心是最常见 WA）。
见 [notes/palindrome-family.md](../notes/palindrome-family.md)。

### 同向·快慢：慢指针的三重身份

`k` 同时是「下一个写入位置」「已有的合法元素个数」「要返回的值」。
半开区间约定见 [structures/array.md](../structures/array.md) §0。

## 3. 拿到新题怎么选

1. **两个序列？** → 归并型，比大小取小的推进，完事。
2. **一个序列，问连续子段的最优？** → 滑窗。先自检：合法性向下封闭吗？不封闭就别套。
3. **一个序列，问一对/一组元素？** → 排序 + 夹逼。前提：能写出「移哪边」的单调依据。
4. **问对称结构？** → 中心扩展，枚举中心不是端点。
5. **以上都不行** → 大概率是 DP：候选丢不掉，只能汇总。

## 4. 各族的坑

- **夹逼**：`while l < r` 不是 `<=`；**先结算当前这对再移动**，顺序反了会漏解（11）
- **滑窗**：`l` 只能前进不能重置；把问题理解成「切段」就从根上漏解（3）
- **扩散**：奇偶两种中心都要跑
- **归并**：一侧走完后，**剩下那截要整段接上**（88 忘过一次）
- **快慢**：用 `while` 不用 `for`，手动更新下标才想得清楚什么时候不该推进（27）
