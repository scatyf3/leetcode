2. 从 nums.length == n + 1 出发 —— 把 i -> nums[i] 看成一张图上的走法,每个点出度 1。为什么下标 0 一定不在环里(想想值域下界)?那么「重复的那个值」在这张图上是什么?—— 这条能做到 O(n) / O(1)。
