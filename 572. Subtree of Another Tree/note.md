很神秘，这里不能dfs包办一切，dfs包办的failure case是

```
root:  2 (A)        subRoot:  2 (S)
      /                      /
     2 (B)                  3 (T)
    /
   3 (C)

```

你的写法在 A 处发现 2 == 2，就切进判同、把 subRoot 拆成了 S.left = T。接着比 B(2) vs T(3)，不匹配。

此刻正确的动作是"拿完整的 S 去和 B 比"——而 B 和 S 恰好是一样的，答案是 True。但你手上只有被拆过的 T，完整的 S 已经在递归里丢了。

外层递归的唯一作用，就是在每个节点上都持有一份完整的 subRoot。它提供的不是"另一种遍历"，而是回溯点。

而且edgecase好复杂，一个好办法是列表列举，是否cover掉全部edge case
