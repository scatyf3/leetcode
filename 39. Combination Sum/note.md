
为啥不能sort+双指针？或者这个解法能写成回溯同款吗？
不行，双指针的要求是
1. 单调性（所以要 sort）
2. 未知数的个数固定且已知


或者说双指针是回溯的特例?
不是

3sum可以写双指针

```python
def threeSum(nums):
    nums.sort()
    res, path = [], []
    def bt(start, remain, k):              # k = 还要再选几个数
        if k == 0:
            if remain == 0: res.append(path[:])
            return
        for i in range(start, len(nums) - k + 1):     # -k+1: 剩下的位置不够就别开了
            if i > start and nums[i] == nums[i-1]: continue   # 同层去重
            path.append(nums[i])
            bt(i + 1, remain - nums[i], k - 1)        # i+1: 每个数只用一次
            path.pop()
    bt(0, 0, 3)
    return res
```

两个都能解不代表是特例，这里的区别是

|            | 回溯                          | 双指针                     |
| ---------- | ----------------------------- | -------------------------- |
| 指针/状态  | 走下去，**再退回来**（`path.pop()`） | `l` 只增、`r` 只减，**永不倒退** |
| 形状       | 树（每层 fan out）            | 一条直线                   |
| 同一个状态 | 可能被反复进入                | 每个位置最多访问一次       |
| 复杂度量级 | 指数                          | 线性                       |


这里的族谱是
```
穷举
 └─ 回溯 (DFS + 剪枝)
      └─ 子集/排列/N皇后/组合总和

排除法(靠单调性)
 ├─ 二分            ← 一次砍一半
 └─ 双指针          ← 一次砍一行/一列
      └─ 相向 / 同向(滑窗) / 快慢
```

回溯就是dfs吗？
回溯 = DFS + 撤销状态 + 剪

图 DFS	回溯
树/图	显式存在（给你的 grid、邻接表）	隐式，由"做选择"现场生成
要的答案	点集、连通性、可达性	路径本身
记录在哪	visited 全局单调增长	path 随进出伸缩
重复访问	必须避免（防环、防冗余）	必须允许（不同路径可复用同一元素）


所以回溯和图/tree dfs区别是它
1. 遍历一个隐式的东西，可以撤销
2. 回溯要的是每一条路径，DFS 要的是哪些点可达。


DFS 问"哪些地方能到"，回溯问"到那儿的每一条路分别长什么样"。

网格题里这条线最容易看清。同样是 grid + DFS：
200. 岛屿数量：visited 标记后永不撤销——一个格子属于哪个岛是确定的，问的是"有几片连通块"。→ DFS
79. Word Search：在格子里找单词路径，走不通必须把 visited 撤销掉，因为这个格子在另一条路径上还能用。→ 回溯
