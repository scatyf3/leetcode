### 双指针(排除法) vs 滚动 DP(汇总法)

| | 11 / 42 的双指针 | 152 的滚动 DP |
|---|---|---|
| 每步做什么 | **永久丢掉一个候选**(指针内移) | **什么都不丢**,把全部历史汇总进两个数 |
| 变量是什么 | `l`/`r` 是**下标**,指向还活着的边界 | `mx`/`mn` 是**值**,和位置无关 |
| 正确性靠什么 | **支配论证**:被丢的那个,上限已经算过了 | **状态完备**:三个候选覆盖了所有转移来源 |
| 搜索空间 | 单调收缩,`n` 步耗尽 | 不收缩,只是每步 `O(1)` 汇总掉 |
| `O(n)` 从哪来 | 每步删一个候选 | 每个位置 `O(1)` 转移 |
| 空间为什么小 | 本来就不需要数组 | 数组**本来存在**,被滚动压掉了 |

**决定性的一问:能不能证明"某个候选永远不可能更优"?**

- 能证明 → 丢掉它 → 双指针。LC11 里短板的高度封顶、宽度也封顶,潜力耗尽。
- 证不出来 → 必须留着 → DP。LC152 里 `mn` 现在最差,但乘个负数就翻身,潜力没耗尽。
