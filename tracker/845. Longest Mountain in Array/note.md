# 845. Longest Mountain in Array

好像是个语义复杂的扫描啊，涉及到状态机

## 状态机

`up`/`down` 两个 bit 编码三个状态，`cur` 记当前山的**边数**(元素数 = cur + 1)。

```
                          <  cur=1
           ┌─────────────────────────────────┐
           │                                 ▼
     ┌───────────┐                     ┌───────────┐
 >,= │    00     │                     │    10     │ <  cur+=1
 ┌──▶│  平地/起点 │                     │  上坡中   │◀──┐
 └───│  cur=0    │◀────────────────────│           │───┘
     └───────────┘          =          └───────────┘
           ▲                              │      ▲
           │                    > cur+=1  │      │  < cur=1
           │                    结算 res  │      │ (谷底就是新山的起点)
           │                              ▼      │
           │          =                ┌───────────┐
           └───────────────────────────│    11     │ > cur+=1
                                       │  下坡中   │   结算 res
                                       │ (合法的山)│◀──┐
                                       └───────────┘───┘
```

| 状态 \ 输入 | 上升 `<` | 下降 `>` | 相等 `=` |
|---|---|---|---|
| 00 | → 10，cur=1 | 留 00 | 留 00 |
| 10 | 留 10，cur+=1 | → 11，cur+=1，**结算** | → 00，cur=0 |
| 11 | → 10，**cur=1** | 留 11，cur+=1，**结算** | → 00，cur=0 |

> 结算只挂在**指向 11 的两条边**上：进入或停在 11 就是合法的山，当场 `res = max(res, cur + 1)`。
> 所以相等分支只重置、循环结束后不用补结算，全相等永远进不了 11，`res` 初值 0 直接返回。

## 第一版踩的坑

1. 回到 00 没清 `cur` —— 第二座山接着第一座累加
2. 11 碰到上升转回了 00 —— 谷底是两座山共用的(`[1,3,1,4,1]`)，应该转 10 且 `cur=1`，否则丢一段上坡
3. 相等分支不管状态都结算 —— 10 遇到相等时只有上坡，不是山
4. 只在**离开** 11 时结算 —— 数组末尾还在 11(`[0,1,0]`)就漏了最后一座

2、3、4 的共同解法：结算从「离开 11」挪到「进入 / 停在 11」。

## 代码

```python
class Solution:
    def longestMountain(self, arr: list[int]) -> int:
        res = 0
        up = 0
        down = 0
        # state machine 00 -> 10 -> 11 -> 10 / 00
        cur = 0  # 当前山的边数, 元素数 = cur + 1
        for i in range(1, len(arr)):
            if arr[i-1] < arr[i]:  # increase
                if up == 0 and down == 0:
                    up = 1
                    cur = 1
                elif up == 1 and down == 0:
                    cur += 1
                elif up == 1 and down == 1:
                    # 谷底同时是新山的起点: 这一步就是新山的第一段上坡
                    down = 0
                    cur = 1
            elif arr[i-1] > arr[i]:  # decrease
                if up == 1:  # 10 -> 11, 或 11 留在 11
                    down = 1
                    cur += 1
                    res = max(res, cur + 1)  # 处在 11 就是合法的山, 当场结算
                # 00 碰到下降: 留在 00, 不用管
            else:  # equal
                up = 0
                down = 0
                cur = 0
        return res
```

验证：`[0,1,0]` → 3，`[1,3,1,4,1]` → 3，`[2,2,2]` → 0，`[2,1,4,7,3,2,5]` → 5。
