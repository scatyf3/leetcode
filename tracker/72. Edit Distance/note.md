# 72. Edit Distance

依旧是dp，这里的语义是: dp[i][j]: 把 word1[:i] 变成 word2[:j] 的最少操作数

三种状态转移
```python
dp[i][j] = 1 + min(
     dp[i][j-1],   # 删除
     dp[i-1][j],   # 插入
     dp[i-1][j-1],   # 替换
)
```

inital state是边，初始化边


---

### 注释写反了

代码是对的（三项取 min，顺序不影响），但标签反了：

```python
dp[i][j] = 1 + min(
    dp[i-1][j],     # 删除 word1[i-1]
    dp[i][j-1],     # 插入 word2[j-1]
    dp[i-1][j-1],   # 替换 word1[i-1] → word2[j-1]
)
```

### 怎么理解三种转移

问自己：**结果的最后一个字符 `word2[j-1]` 是从哪来的？** 只有三种来源，正好覆盖所有可能：

1. **由 `word1[i-1]` 变来**：两个字符相等就不花操作，不等就花 1 次**替换**。两边末尾都处理完了 → 剩 `word1[:i-1]` → `word2[:j-1]`，即左上 `dp[i-1][j-1]`
2. **新插入的**：花 1 次**插入**，没碰 `word1` → 剩**完整的** `word1[:i]` → `word2[:j-1]`，即左方 `dp[i][j-1]`
3. **都不是**：说明 `word1[i-1]` 在结果里没有对应的字符，只能**删除**。`word2` 一个都没对上 → 剩 `word1[:i-1]` → 完整的 `word2[:j]`，即上方 `dp[i-1][j]`

用两个指针来记（指在两个字符串末尾）：

| 操作 | word1 指针 | word2 指针 | 来自 |
|---|---|---|---|
| 替换 / 相等 | 往前一格 | 往前一格 | 左上 `[i-1][j-1]` |
| 插入 | 不动 | 往前一格 | 左 `[i][j-1]` |
| 删除 | 往前一格 | 不动 | 上 `[i-1][j]` |

> 哪边被「消耗」了，哪边的下标就减 1。插入消耗的是 word2 的字符，所以减 j，不是减 i。

例子 `"horse"` → `"ros"`，比较末尾的 `'e'` 和 `'s'`：

- 替换 `'e'`→`'s'`：剩 `"hors"` → `"ro"`
- 插入 `'s'`：剩 `"horse"` → `"ro"`
- 删除 `'e'`：剩 `"hors"` → `"ros"`

### 为啥 word1 插入，却是 word2 往前一格

关键在**指针的含义**：不是「编辑后字符串里的位置」，而是「还有哪些字符没处理」。

- `i`：word1 的**原始字符**还剩 `word1[:i]` 没处理
- `j`：word2 的**目标字符**还剩 `word2[:j]` 没凑出来

在 word1 末尾插入一个字符，它就等于 `word2[j-1]`：

- 对 word2：最后一个目标字符凑出来了 → `j → j-1`
- 对 word1：插入的字符是新加的，原始字符一个都没用掉 → `i` 不动

例子 `"ab"` → `"abc"`：

```
word1 原始: a b
插入 'c'  : a b [c]      ← [c] 是新加的，不是原来的字符
word2     : a b  c
                 ↑ 被 [c] 配上了，处理完
```

剩 `"ab"` → `"ab"`，即 `dp[2][2] = 0`，所以 `dp[2][3] = 1 + dp[2][2] = 1`，这一步来自 `dp[i][j-1]`。

删除对照着看：删掉 `word1[i-1]`，用掉的是一个原始字符 → `i-1`；word2 还没凑出任何字符 → `j` 不动。

> 插入用掉一个目标字符，删除用掉一个原始字符。用掉哪一边的字符，哪一边的下标就减 1。

### 边界

LCS 里空串对应 0，这里不是：`dp[i][0] = i`（全删），`dp[0][j] = j`（全插入），要单独初始化。

### 和 LCS 的关系

骨架完全一样（见 [1143](../1143.%20Longest%20Common%20Subsequence/note.md)）。LCS 的「不等时跳过某一边」对应这里的删除 / 插入，「相等时两边一起前进」对应替换 / 相等。区别只在于 LCS 求能匹配的最大值，Edit Distance 求操作的最小代价。
