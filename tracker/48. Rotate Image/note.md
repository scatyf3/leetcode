## Hint 1：先分清两个方向的映射

这是最容易绕晕的地方，先约定清楚你要哪一个：

- **正向（push）**：老位置 `(i,j)` 的值应该去哪 → `new[?][?] = old[i][j]`
- **反向（pull）**：新位置 `(i,j)` 该从哪取 → `new[i][j] = old[?][?]`

两者互为逆映射。写循环时用哪个都行，但混用必错。

## Hint 2：三种推导方式，挑一个顺手的

**(a) 观察法。** 拿 3×3 那个例子，只盯第一行 `1 2 3`。旋转后它去哪了？变成了最后一列 `1,2,3`（从上往下）。即第 0 行 → 第 `n-1` 列，且行内顺序保持。推广：第 `i` 行 → 第 `n-1-i` 列，行内第 `j` 个 → 该列第 `j` 个。

**(b) 分解法（最好记，已整理进 [matrix-index-transform.md](../notes/matrix-index-transform.md)）。** 顺时针 90° = **转置** + **每行反转**。分别写出两步的映射再复合：

- 转置：`(i,j) → (j,i)`
- 每行反转：`(i,j) → (i, n-1-j)`

把第一步的结果代进第二步，就得到最终映射。这个方法的好处是它同时也是一种**实现方案**（两趟 in-place，代码超短），而且逆时针只要换成"转置 + 每列反转"。

**(c) 坐标法。** 把矩阵下标看成平面坐标，绕中心转 90°。注意行号 `i` 是向下增长的，所以屏幕坐标系下的"顺时针"对应数学坐标系的"逆时针"——这个符号坑很容易翻车，除非你想练线代，否则推荐 (a)/(b)。

按 (a) 或 (b) 推完，你会得到一个形如 `(i,j) → (j, n-1-i)` 的式子。**自己验一遍**：`n=3`，`(0,0)` 的 1 应该落在 `(0,2)`，对照 output `[[7,4,1],...]`。

## Hint 3：用这个映射做 in-place

关键性质：**这个映射的阶是 4**——连续套用 4 次回到原点。所以每个元素属于一个 4 元环：

```
(i,j) → (j, n-1-i) → (n-1-i, n-1-j) → (n-1-j, i) → 回到 (i,j)
```

于是只需要 **1 个临时变量**，一次性把这 4 个位置轮转好。

剩下的问题是：**遍历哪些 `(i,j)` 能不重不漏地覆盖所有环？** 提示——每个环恰好在四个"象限"各占一个点，所以只遍历左上角一块即可。`n` 为奇数时中心那个点自成一环（不用动），边界要留意：一层的行数和列数不是对称的 `n//2 × n//2`，想想 3×3 时左上角该取几个点（答案是 2 个，不是 1 个）。
