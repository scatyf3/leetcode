只有一处措辞要收紧：「non loop」不够准确。safe 的意思是**怎么走都进不了环**，不只是「自己不在环上」：

```
0 → 1 ⇄ 2 → 3

1、2 在环上            → 不 safe
0 不在环上，但会走进环   → 也不 safe
3 是终点               → safe
答案：[3]
```

**这也是必须反转的原因**

| | 先删谁 | 这个例子里删掉的点 |
|---|---|---|
| 正图 Kahn | 没人指向它的点（入度 0） | 0 ✗ 不 safe 却被删了，3 ✗ 却被环卡住删不掉 |
| 反图 Kahn | 终点（原图出度 0） | 3 ✓，然后 2 还有一条边指向 1，停住 |

反图 Kahn 的含义是：终点 safe；一个点的**所有**出边都指向 safe 的点，它才 safe。反图的 `indeg` 就是原图的出度，每确认一个 dst safe 就减 1，减到 0 说明全部出边都安全了。

#### 🤖 Claude

因为「不在环上」的点分两种，其中一种不 safe：

```
0 → 1 ⇄ 2 → 3
```

| 点 | 在环上吗 | safe 吗 | 原因 |
|---|---|---|---|
| 1、2 | 在 | 否 | 可以一直绕圈 |
| **0** | **不在** | **否** | 走一步到 1，之后可以一直绕圈 |
| 3 | 不在 | 是 | 已经是终点 |

题目的 safe 是**从这个点出发，所有路径都会停在终点**，看的是以后会不会走进环，不是自己在不在环上。0 是 nonloop，但不 safe。

**你的做法没错，只是这个名字不准**：反图 Kahn 删掉的本来就不是「所有 nonloop 的点」。用反图走一遍：

```
反图：3 → 2 ⇄ 1 → 0

indeg：3 是 0，2 是 2，1 是 1，0 是 1
删 3 → 2 的 indeg 变 1，停住
1、2 互相卡着，删不掉
0 要等 1 被删，所以也删不掉
```

剩下的是 0、1、2，其中 0 是被环**连累**的。

所以 Kahn 的一般结论是：**删不掉的 = 环上的点 + 环下游的点**（从环出发能走到的点）。反图里环的下游，就是原图里能走进环的点，正好都是不 safe 的。

**为什么 2876 里「删不掉 = 在环上」成立**：函数图每个点只有一条出边，环上的点已经用它走环了，环没有别的下游，所以剩下的恰好是环本身。这题出边可以有多条，这个结论就不能直接套过来。
