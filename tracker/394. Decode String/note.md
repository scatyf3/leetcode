# 394. Decode String

### pass3（2026-10-14）

又写乱了两次，都是「cur 不再只代表当前层」：

1. `[` 压栈后没清零 → 外层的字符和数字留在 cur 里
2. `]` 写成 `cur_counter = cur_number_stk.pop()` → 用完没清零，`3[a]2[bc]` 里 `2` 接在残留的 3 后面变成 32，输出 `aaa` + 32 个 `bc`

> **`[` 存档 + 清空，`]` 读档 + 合并。栈里只放「外层的」，cur 永远只代表「当前这一层」。**
> 弹出来的值用局部变量 `k` 接，只在合并那一行用。

想不清楚时先写递归版（每层自己的 `res` / `num`，天然不会串），再逐行翻译成栈。
栈的几种用法和递归 → 栈的翻译表见 [paradigms/stack.md §4](../../blog/docs/paradigms/stack.md#4-上下文栈--手写的递归调用栈)。

### pass1

第一版：从 `[` 往后找第一个 `]` —— 遇到嵌套（`3[a2[c]]`）会配错；数字也只读了一位。

为啥 k 随着 prev 一起取出来，但是乘在 cur 上，这对吗？

```python
class Solution:
    def decodeString(self, s: str) -> str:
        # stack的状态机，和函数一摸一样
        stack = []          # 存 (进入 [ 之前拼好的字符串, 重复次数), 即之前正在处理的state
        cur, num = "", 0    # 当前层正在拼的字符串、正在读的数字

        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)        # "12" → 1 → 12
            elif ch == "[":
                stack.append((cur, num))        # 把外层的进度先存起来
                cur, num = "", 0                # 括号里从空开始拼
            elif ch == "]":
                prev, k = stack.pop()           # 取回外层的进度
                cur = prev + cur * k            # 括号里的内容重复 k 次，接到外层后面
            else:
                cur += ch

        return cur
```

---

### 例子：`3[a2[b]]`

| 读到 | 动作 | `cur` | `num` | 栈（被暂停的外层） |
|---|---|---|---|---|
| `3` | `num = 0*10+3` | `""` | 3 | `[]` |
| `[` | 存 `("", 3)`，进入新一层 | `""` | 0 | `[("",3)]` |
| `a` | `cur += "a"` | `"a"` | 0 | `[("",3)]` |
| `2` | `num = 0*10+2` | `"a"` | 2 | `[("",3)]` |
| `[` | 存 `("a", 2)`，进入新一层 | `""` | 0 | `[("",3), ("a",2)]` |
| `b` | `cur += "b"` | `"b"` | 0 | `[("",3), ("a",2)]` |
| `]` | 取出 `("a",2)`：`"a" + "b"*2` | `"abb"` | 0 | `[("",3)]` |
| `]` | 取出 `("",3)`：`"" + "abb"*3` | `"abbabbabb"` | 0 | `[]` |

用函数调用的视角看，每对括号是一次调用：

```
第 0 层（最外面）  cur=""
  └─ 读到 3[  → 暂停第 0 层，存 ("", 3)，调用第 1 层
     第 1 层  cur="a"
       └─ 读到 2[  → 暂停第 1 层，存 ("a", 2)，调用第 2 层
          第 2 层  cur="b"
          读到 ]  → 第 2 层返回 "b"
       第 1 层恢复：  "a" + "b"*2 = "abb"
       读到 ]  → 第 1 层返回 "abb"
  第 0 层恢复：  "" + "abb"*3 = "abbabbabb"
```

| 函数调用 | 本题 |
|---|---|
| 调用前把局部变量压栈 | `[`：把 `(cur, num)` 压栈 |
| 进入被调函数，局部变量全新 | `cur, num = "", 0` |
| 被调函数 return 一个值 | `]` 时的 `cur` 就是这一层的返回值 |
| 调用方恢复局部变量，拿返回值继续算 | `prev, k = stack.pop()`，`cur = prev + cur * k` |

**k 为什么和 prev 一起存、却乘在 cur 上**：`a2[b]` 里，`2` 修饰的是后面的 `[b]`，和前面的 `a` 无关。`(prev, k)` 应该读成「括号外面已经有的内容」+「这对括号要重复几次」，它俩只是在同一时刻（`[`）存、同一时刻（`]`）取，才放在一个元组里。拆成 `str_stack` / `num_stack` 两个栈是一回事。存进去的 `num` 相当于「调用参数」，要等被调的那层返回后，在调用方这边才用上。

> 栈 + `cur` = 手动模拟递归。同样的套路：[224. Basic Calculator](https://leetcode.com/problems/basic-calculator/) / [227. Basic Calculator II](https://leetcode.com/problems/basic-calculator-ii/)，遇 `(` 把 `(当前结果, 符号)` 压栈，遇 `)` 弹出合并。
