#### 🤖 Claude

按每个连通块分开看。一个有 k 块石头的连通块，**最多删 k − 1 块，而且一定能删到 k − 1 块**。所有块加起来就是 n − 连通块数。

### 为什么最多删 k − 1：每个块至少剩 1 块

- 不同连通块里的石头，按定义不会同行也不会同列，所以块和块之间互不影响。
- 删一块石头的前提是：还有另一块活着的石头和它同行或同列。这块"同伴"只能在同一个连通块里。
- 所以一个块删到只剩最后 1 块时，这块就找不到同伴了，删不掉。

### 为什么一定能删到 k − 1：从叶子往里删

- 在这个连通块上做一次 DFS，得到一棵生成树，k 个节点，k − 1 条边。
- 每次删一片**叶子**：
  - 叶子的父节点还活着，而它们之间有边（同行或同列），所以这次删除合法。
  - 删掉叶子不会把树断开，剩下的部分还是一棵连通的树。
- 一直删到只剩根，正好删了 k − 1 块。

### 对照之前的反例

`(0,0) — (0,1) — (1,1)` 是一条链，`(0,1)` 在中间，是**内部节点**。先删它，树就断成两个孤立点，每个点都要剩 1 块，所以只删了 1 块。

从两头的叶子开始删，就能删 2 块。这也说明光有"行/列 set 的 size>1"这个信息不够：它看不出哪块是叶子、哪块是中间的连接点。

#### 🤖 Claude

有道理，核心就一句话：

> **能删的石头数 = 生成森林的边数，而 n 个节点、c 个连通块的生成森林恰好有 n − c 条边。**

### 一条边对应一块被删的石头

把每个连通块的生成树都画出来，并选好根，比如就选最后留下的那块。

- 每块**非根**石头，都有一条连向父节点的边。
- 删这块石头时，靠的就是这条边：父节点还活着，并且和它同行或同列。
- 所以每块被删的石头，正好对应一条树边，反过来每条树边也正好对应一块被删的石头。

所以"能删几块"其实就是"树里有几条边"。

### 为什么是 n − c

这是树的基本性质：

- 一棵 k 个节点的树有 k − 1 条边。
- c 棵树、总共 n 个节点，边数是 (k₁ − 1) + (k₂ − 1) + … = **n − c**。
- 换个角度看：一开始 n 块石头各自是一个块，每加一条有效的边，块数就少 1。从 n 个块并到 c 个块，正好用了 n − c 条边。并查集里每次成功的 union 就是在加这样一条边。

### 这是一个常见套路

> 一个操作需要同一个连通块里的"同伴"才能做，那么每个块最后必然剩 1 个，答案就是 n − 连通块数。

同一个思路还出现在：

- **1319. Number of Operations to Make Network Connected**：答案是 连通块数 − 1。
- **并查集统计"多余的边"**：总边数 − (n − c)。

以后看到"删除或操作需要有邻居 / 同伴"的题，可以先想想答案是不是由连通块数决定的。

有区别。dict 只解决了"不用知道最大值"这个问题，**没有解决行和列撞编号的问题**。

关键在于 dict 是按 key 区分节点的：

```python
parents = {}
parents[3] = 3   # 你想表示"第 3 行"
parents[3] = 3   # 你想表示"第 3 列"
```

这两行写的是**同一个 key 3**。dict 里只有一个条目，所以第 3 行和第 3 列还是被当成了同一个节点。

dict 并不知道你传进来的 3 是行号还是列号，它只认 key。所以 key 本身就得带上"我是行还是列"的信息：

```python
parents[('r', 3)]   # 第 3 行
parents[('c', 3)]   # 第 3 列，和上面是不同的 key
```

或者：

```python
parents[3]          # 第 3 行
parents[~3]         # 第 3 列，key 是 -4，不会和任何行号重复
```

### 总结

| 问题 | list | dict |
|---|---|---|
| 需要知道最大 x、y 吗 | 需要 | 不需要 |
| 没出现过的行/列会被误数成连通块吗 | 会 | 不会 |
| 行 3 和列 3 会撞吗 | 会，要加偏移 | **也会，要用 tuple 或 `~y`** |

所以不管用 list 还是 dict，行和列都要错开编号。

下面是一个通用的 dict 版并查集模板，以后其他并查集题也能直接用：

```python
class UF:
    def __init__(self):
        self.parent = {}
        self.count = 0              # 当前连通块数

    def find(self, x):
        if x not in self.parent:    # 第一次见到这个节点：自成一块
            self.parent[x] = x
            self.count += 1
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # 路径压缩：指向爷爷
            x = self.parent[x]
        return x

    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False            # 本来就连通，多余的边
        self.parent[ra] = rb
        self.count -= 1             # 两块合成一块
        return True
```

要点有三个：

1. **按需创建节点**：`find` 第一次碰到某个节点时，才把它放进 dict，同时 `count + 1`。所以 dict 里只有出现过的节点，不用知道最大值。
2. **`count` 随时就是连通块数**：新节点出现时 +1，每次成功 union −1。这就是前面说的"出现过的节点数 − 成功合并次数"，不需要最后再扫一遍数根。
3. **路径压缩**：往上找根的同时，把每个节点改成指向它的爷爷，路径会越走越短。

### `find(x)`：找 x 所在连通块的"代表"，也就是根

每个连通块是一棵树，`parent[x]` 存的是 x 的父节点，根的父节点是它自己。`find` 就是从 x 一路往上走，走到根为止。

代码分三段：

1. **按需创建节点**
   ```python
   if x not in self.parent:
       self.parent[x] = x
       self.count += 1
   ```
   第一次见到 x 时，让它自己当根，自成一块，所以连通块数 +1。

2. **往上走到根**
   ```python
   while self.parent[x] != x:
       x = self.parent[x]
   ```
   直到 `parent[x] == x`，说明 x 就是根。

3. **路径压缩**
   ```python
   self.parent[x] = self.parent[self.parent[x]]
   ```
   每走一步，先把 x 的父亲改成它的爷爷，再往上跳。这样路径会越压越短，以后再 find 就快了。

   例子：一条链 `a → b → c → d`，d 是根。
   - 在 a：把 a 的父亲改成 c，然后跳到 c。
   - 在 c：c 的父亲 d 就是根，把 c 的父亲改成 d 的父亲（还是 d），然后跳到 d。
   - d 是根，结束，返回 d。
   - 结果变成 `a → c → d`，`b → c`，树变矮了。

**用途**：两个节点 find 出来的根相同，就说明它们在同一个连通块里。

### `union(a, b)`：把 a 和 b 所在的两个块合成一块

```python
ra, rb = self.find(a), self.find(b)
```
先找到两个根。如果 a、b 是新节点，这一步会顺便把它们创建出来。

```python
if ra == rb:
    return False
```
根相同，说明本来就连通，不用做任何事。返回 False 表示这是一条"多余的边"。

```python
self.parent[ra] = rb
self.count -= 1
return True
```
把一个根挂到另一个根下面，两棵树就合成了一棵，连通块数 −1。注意挂的是**根**，不是 a 本身。如果只改 `parent[a]`，a 原来那棵树里的其他节点会被留在原地。

### 小例子

```
union(1, 2)   新建 1、2 → count = 2；合并 → count = 1   树：1 → 2
union(3, 4)   新建 3、4 → count = 3；合并 → count = 2   树：3 → 4
union(1, 3)   find(1) = 2，find(3) = 4，挂 2 → 4，count = 1
union(2, 4)   find(2) = 4，find(4) = 4，根相同，返回 False，count 不变
```

最后 1、2、3、4 都在一个块里，count = 1。
