## 核心等式

对任意实数 x，有 `|x| = max(x, -x)`。所以：

```
|a| + |b| + |c| = max over (s1, s2, s3) ∈ {±1}³ of (s1·a + s2·b + s3·c)
```

令 `a = arr1[i]-arr1[j]`，`b = arr2[i]-arr2[j]`，`c = i-j`，代进去得到：

```
s1·(arr1[i]-arr1[j]) + s2·(arr2[i]-arr2[j]) + s3·(i-j)
= f(i) - f(j)，其中 f(k) = s1·arr1[k] + s2·arr2[k] + s3·k
```

i 的部分和 j 的部分分开了。固定一组符号后，`max(f(i) - f(j))` 就等于 `max(f) - min(f)`，扫一遍就能求出来。

还有一个优化：`(s1, s2, s3)` 和 `(-s1, -s2, -s3)` 得到的 f 只差一个负号，`max - min` 完全相同。所以 8 种符号组合里只需要算 4 种，固定 `s3 = +1` 就行。

## 代码

```python
class Solution:
    def maxAbsValExpr(self, arr1: list[int], arr2: list[int]) -> int:
        res = 0
        for s1, s2 in ((1, 1), (1, -1), (-1, 1), (-1, -1)):
            hi = lo = s1 * arr1[0] + s2 * arr2[0]
            for k in range(1, len(arr1)):
                v = s1 * arr1[k] + s2 * arr2[k] + k
                hi = max(hi, v)
                lo = min(lo, v)
            res = max(res, hi - lo)
        return res
```

时间复杂度 O(n)（4 遍扫描），空间复杂度 O(1)。

## 第 1 步：一个绝对值等于「两个候选里取大的」

`|x| = max(x, -x)`

## 第 2 步：两个绝对值相加，就是四个候选里取最大

```
a + b,   a - b,   -a + b,   -a - b

验证一下，取 `a = 2`，`b = -5`：

| 符号 | 值 |
|---|---|
| a + b | -3 |
| a - b | **7** |
| -a + b | -7 |
| -a - b | 3 |

最大是 7，正好等于 `|2| + |-5|`。原因是：符号猜对的那一项会把每个数都变成正的，其他猜错的项总会偏小。

## 第 3 步：调换顺序，先固定符号

题目要求的是：

> 所有 (i, j) 中，「所有符号组合中的最大值」的最大值

两个「取最大」可以交换顺序，所以等价于：

> 所有符号组合中，「所有 (i, j) 中的最大值」的最大值

也就是说，先挑一组符号，固定下来，在这组符号下找最好的 (i, j)。每组符号都这样做一遍，最后取最大。

## 第 4 步：符号固定以后，i 和 j 就分开了

```
(arr1[i] - arr1[j]) + (arr2[i] - arr2[j]) + (i - j)
= (arr1[i] + arr2[i] + i) - (arr1[j] + arr2[j] + j)
```

定义 `f(k) = arr1[k] + arr2[k] + k`，上面这个式子就是 `f(i) - f(j)`。

要让 `f(i) - f(j)` 最大，i 取 f 最大的位置，j 取 f 最小的位置，所以答案就是 **`max(f) - min(f)`**。不用再枚举 (i, j) 对了，扫一遍数组就够。

## 从最简单的版本开始

先把题目砍到只剩一项：**求 `|a[i] - a[j]|` 的最大值。**

这个大家都会：答案就是 `max(a) - min(a)`，不用枚举 (i, j)。

为什么这么容易？因为绝对值的最大值，就是让大的减小的。差值 `a[i] - a[j]` 里 i 和 j 各管各的，所以各自取极值就行。

## 加一项会遇到什么问题

**求 `|a[i] - a[j]| + |b[i] - b[j]|` 的最大值。**

这时候不能各自取极值了。让 a 差最大的那对 (i, j)，和让 b 差最大的那对，不一定是同一对。两项被绝对值绑在一起，拆不开。

所以真正的障碍只有一个：**绝对值。** 如果没有绝对值，`(a[i]+b[i]) - (a[j]+b[j])` 就又是 `max - min` 了。

## 去掉障碍：猜符号

绝对值的作用其实只是「把符号翻成正的」。我们不知道 `a[i]-a[j]` 是正是负，那就两种都猜，四种组合全试一遍。

关键在于，**猜错不会让答案变大**：
- 猜对的那一组，算出来正好等于真实值；
- 猜错的组，比如把正数当负数来减，只会更小。

所以对所有猜法取最大值，一定得到正确答案，不会多算。这一点就是正确性的来源。

每一组猜法都没有绝对值了，于是又回到了最开始那个简单问题，扫一遍取 `max - min` 就行。

## 1. 分离 i 和 j

如果式子能写成 `f(i) - f(j)` 或 `f(i) + g(j)`，就不用枚举 (i, j) 对：
- 只要求最大值、对 i < j 没有限制时，直接取 `max(f) - min(f)`；
- 有 `i > j` 的限制时，从左往右扫，边扫边维护前面见过的最小值（「枚举右，维护左」）。

纯练这一步的题：**1014. Best Sightseeing Pair**。它的式子是 `values[i] + values[j] + i - j`，没有绝对值，直接拆成 `(values[i] - i) + (values[j] + j)` 就行。

## 2. 枚举符号去掉绝对值

`|a| + |b| + ...` 等于对所有符号组合取 max。有绝对值、拆不开的时候，先用这一招把绝对值去掉，再交给第 1 步。

这个组合最常见的名字是**曼哈顿距离转切比雪夫距离**：

```
|x1-x2| + |y1-y2| = max(|u1-u2|, |v1-v2|)，其中 u = x+y，v = x-y
```

意思是把坐标转 45° 之后，曼哈顿距离就变成「两个维度的差取较大的那个」，而每个维度的差都可以直接用 `max - min` 求。

## 什么时候该想到它

- 题目要在所有 (i, j) 对中求最大或最小；
- 式子是几项 `|x_i - x_j|` 相加，而且项数少（d 项要枚举 2^(d-1) 种符号）；
- n 很大，O(n²) 会超时。

    def maxAbsValExpr(self, arr1: list[int], arr2: list[int]) -> int:
        res = 0
        for s1, s2 in ((1, 1), (1, -1), (-1, 1), (-1, -1)):

#### 🤖 Claude

「左边」指的是**当前位置 k 之前已经扫过的下标**，也就是 `0, 1, ..., k-1`。

## 为什么要看左边

我们固定了 i > j，所以 j 一定在 i 的前面。扫到 k 的时候，把 k 当成 i，那么 j 只能从 k 左边挑。为了让 `v[i] - v[j]` 最大，j 要挑左边 v 最小的那个。

所以 `mn` 的含义是：

> **mn = v[0], v[1], ..., v[k-1] 里的最小值**

## 画出来

以 `v = [5, 3, 8, 1, 6]` 为例：

```
扫到 k=0:  [ ]            | 5      左边是空的，mn = ？
扫到 k=1:  [5]            | 3      mn = 5
扫到 k=2:  [5, 3]         | 8      mn = 3   → 8 - 3 = 5
扫到 k=3:  [5, 3, 8]      | 1      mn = 3
扫到 k=4:  [5, 3, 8, 1]   | 6      mn = 1   → 6 - 1 = 5
```

竖线左边就是「左边」。每扫完一个位置，它就被并进左边，留给后面的位置使用。

## 初值是什么意思

初值就是 k = 0 时 mn 该等于多少。这时左边**一个元素都没有**，没有 j 可以选。

所以初值要满足两点：

1. **不能让答案被更新**：k = 0 时会算 `v - mn`，这个值必须很小，不能影响 res。
2. **第一次取 min 时要被替换掉**：执行 `min(mn, v[0])` 之后，mn 必须变成 `v[0]`。

`float('inf')` 两点都满足：`v - inf = -inf`，不会更新 res；`min(inf, v[0]) = v[0]`。

你可以把 inf 理解成「还没有任何值」的占位符。求最小值时初值设成 inf，求最大值时初值设成 `-inf`，这个写法是通用的。

v = s1 * arr1[k] + s2 * arr2[k] + k   # 当前位置 k，扮演 i
res = max(res, v - mn)                # mn 是某个更早位置的 v，扮演 j
```

- `v` 是 `v[i]`，用当前下标 k 算出来；
- `mn` 是 `v[j]`，是之前某个下标算出来的 v，被保存了下来；
- `v - mn` 就是 `v[i] - v[j]`，一对 (i, j) 在这里才凑齐。

## 为什么要这样拆

在原式里，i 和 j 混在同一个绝对值里，必须两个下标一起枚举，所以是 O(n²)。

拆开之后，每个下标只需要算出自己的 v。配对的工作交给 mn：它记住了左边最好的那个 j。这样每个位置只算一次，总共 O(n)。

这就是前面说的第一个 pattern「分离 i 和 j」：**先把式子拆成每个下标各算各的，再用一个变量记住左边最好的那个。**

```python
class Solution:
    def maxAbsValExpr(self, arr1: list[int], arr2: list[int]) -> int:
        # 原式：|arr1[i]-arr1[j]| + |arr2[i]-arr2[j]| + |i-j|
        # 规定 i > j（i 在右边，j 在左边），于是 |i-j| = i-j，不用再管它的符号
        res = 0

        # 剩下两个绝对值的符号不知道，四种情况全部试一遍
        # 猜对的那组正好等于原式，猜错的只会偏小，所以最后取最大值就对了
        for s1, s2 in ((1, 1), (1, -1), (-1, 1), (-1, -1)):

            # mn = 目前为止左边所有 v 里的最小值，也就是 j 的最佳选择
            # 一开始左边是空的，用 inf 表示「还没有值」
            mn = float('inf')

            for k in range(len(arr1)):
                # 符号固定以后，原式 = v[i] - v[j]
                # 其中 v[k] = s1*arr1[k] + s2*arr2[k] + k，只用一个下标就能算
                v = s1 * arr1[k] + s2 * arr2[k] + k

                # 把当前的 k 当作 i，配上左边最小的 j：v[i] - v[j] 最大
                # k = 0 时 mn 是 inf，v - inf = -inf，不会更新 res
                res = max(res, v - mn)

                # 把 k 加进「左边」，给后面的位置当 j 用
                # 必须在更新 res 之后执行，否则 k 会和自己配对
                mn = min(mn, v)

        return res
```

想记住的话，可以压缩成三句话：

1. **去绝对值**：规定 i > j，枚举另外两个绝对值的符号，一共 4 组。
2. **分离下标**：每组符号下，原式等于 `v[i] - v[j]`，`v[k]` 只依赖一个下标。
3. **维护左边最小**：从左往右扫，先用 `v - mn` 更新答案，再把 v 并进 mn。
