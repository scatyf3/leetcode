# 1131. Maximum of Absolute Value Expression

## pass1

**第一版**：两个数组各自 sort，再 O(n²) 枚举 (i, j)。

```python
arr1.sort()
arr2.sort()
# some binary search
for i in range(0, n):
    for j in range(i, n):
        res = max(res, abs(arr1[i]-arr1[j]) + abs(arr2[i]-arr2[j]) + abs(i-j))
```

错在 sort：下标 i 绑定的是一个三元组 `(arr1[i], arr2[i], i)`，分开排序之后
`arr1[i]` 和 `arr2[i]` 不再来自同一个原始下标，`|i-j|` 也变成排序后的位置差，算的是另一个问题。

反例：`arr1 = [1, 2]`，`arr2 = [2, 1]`，正确答案是 `|1-2| + |2-1| + |0-1| = 3`，sort 之后就不对了。

去掉 sort，双重循环是对的，但 n ≤ 4×10⁴，O(n²) 会 TLE。另外这题跟二分没关系。

---

### 怎么想到的

先看只有一项的版本：求 `|a[i] - a[j]|` 的最大值，答案就是 `max(a) - min(a)`，因为 i 和 j 各管各的。

加一项变成 `|a[i]-a[j]| + |b[i]-b[j]|` 就拆不开了：让 a 差最大的那一对，不一定让 b 差也最大。
**唯一的障碍是绝对值**。没有绝对值的话，`(a[i]+b[i]) - (a[j]+b[j])` 又回到 max - min。

绝对值的作用只是把符号翻成正的。不知道符号，就把正负都猜一遍：

```
|x| = max(x, -x)
|a| + |b| = max(a+b, a-b, -a+b, -a-b)
```

> 猜对的那一组正好等于真实值，猜错的只会偏小，所以对所有猜法取 max 一定正确，不会多算。

例：`a = 2, b = -5`，四个候选是 -3, **7**, -7, 3，最大值 7 = |2| + |-5|。

### 三步

1. **去绝对值**：规定 i > j，这样 `|i-j| = i-j`，符号确定了。剩下两个绝对值，枚举 4 组符号 `(s1, s2)`。
2. **分离下标**：每组符号下，带 i 的放一起，带 j 的放一起：
   ```
   s1(arr1[i]-arr1[j]) + s2(arr2[i]-arr2[j]) + (i-j)
   = (s1·arr1[i] + s2·arr2[i] + i) - (s1·arr1[j] + s2·arr2[j] + j)
   = v[i] - v[j]，其中 v[k] = s1·arr1[k] + s2·arr2[k] + k
   ```
   v 只依赖一个下标，因为两个括号形状一样，只是代入的下标不同。
3. **维护左边最小**：求 i > j 时 `v[i] - v[j]` 的最大值，和 121 买卖股票一样，从左往右扫，记住左边最小的 v。

### 两个下标去哪了

代码里只写了 k，但 i 和 j 都还在：

- `v` 是 `v[i]`：用当前下标 k 算出来，k 扮演 i
- `mn` 是 `v[j]`：之前某个下标的 v，被保存了下来
- `v - mn` 是 `v[i] - v[j]`：一对 (i, j) 在这里才凑齐

「左边」指已经扫过的下标 `0..k-1`，`mn` 就是这些位置上 v 的最小值。
初值设成 `inf` 表示左边还是空的：`v - inf = -inf`，不会更新 res；`min(inf, v[0]) = v[0]`，第一次取 min 时就被替换掉。

> 求最小值时初值设 `inf`，求最大值时设 `-inf`，「还没有值」都这么写。

### trace

`arr1 = [1, 2]`，`arr2 = [2, 1]`，答案是 3。

四组符号各自的 v：

| (s1, s2) | v[0] | v[1] | v[1] - v[0] |
|---|---|---|---|
| (+, +) | 1+2+0 = 3 | 2+1+1 = 4 | 1 |
| (+, −) | 1−2+0 = −1 | 2−1+1 = 2 | **3** |
| (−, +) | −1+2+0 = 1 | −2+1+1 = 0 | −1 |
| (−, −) | −1−2+0 = −3 | −2−1+1 = −2 | 1 |

`(+, −)` 这一组的扫描过程：

| k | v | 更新前的 mn | v - mn | res | 更新后的 mn |
|---|---|---|---|---|---|
| 0 | −1 | inf | −inf | 0 | −1 |
| 1 | 2 | −1 | **3** | 3 | −1 |

再看一个更长的「维护左边最小」，`v = [5, 3, 8, 1, 6]`，竖线左边就是「左边」：

```
k=0:  [ ]            | 5      mn = inf
k=1:  [5]            | 3      mn = 5
k=2:  [5, 3]         | 8      mn = 3   → 8 - 3 = 5
k=3:  [5, 3, 8]      | 1      mn = 3
k=4:  [5, 3, 8, 1]   | 6      mn = 1   → 6 - 1 = 5
```

### 代码

```python
class Solution:
    def maxAbsValExpr(self, arr1: list[int], arr2: list[int]) -> int:
        # 规定 i > j，于是 |i-j| = i-j；剩下两个绝对值枚举 4 组符号
        res = 0
        for s1, s2 in ((1, 1), (1, -1), (-1, 1), (-1, -1)):
            mn = float('inf')                       # 左边 v 的最小值，空的时候是 inf
            for k in range(len(arr1)):
                v = s1 * arr1[k] + s2 * arr2[k] + k   # 原式 = v[i] - v[j]
                res = max(res, v - mn)              # k 当 i，左边最小的当 j
                mn = min(mn, v)                     # 再把 k 加进左边（顺序不能反）
        return res
```

O(n) 时间，O(1) 空间。

填空时的两个检查问题：

- **④⑤ 能不能交换？** 先把自己并进 mn，k 就会和自己配对。这题里 i = j 时差值是 0，res 从 0 开始，碰巧不出错；
  但像股票那类要求先买后卖的题就错了。习惯是**先用左边更新答案，再把自己加进去**。
- **`+ k` 为什么不枚举符号？** 已经规定 i > j，`|i-j|` 的符号是确定的。

另一种写法是每组符号下直接算 `max(v) - min(v)`，不管 i、j 谁在前。i < j 时相当于 `|i-j|` 的符号猜错了，只会偏小，所以结果也对。
两种写法挑一种记，我记「维护左边最小」这个，和推导一一对应。

### pattern：枚举符号去绝对值 + 分离 i、j

由两个小 pattern 拼起来：

1. **分离 i、j**：式子能写成 `f(i) - f(j)` 或 `f(i) + g(j)` 时，不用枚举 (i, j) 对。没有先后限制就 `max - min`，
   有 i > j 限制就「枚举右，维护左」。
2. **枚举符号去绝对值**：`|a| + |b| + ...` 等于对所有符号组合取 max。d 项要枚举 2^(d-1) 种（固定一项的符号）。

最常见的名字是**曼哈顿距离转切比雪夫距离**：

```
|x1-x2| + |y1-y2| = max(|u1-u2|, |v1-v2|)，其中 u = x+y，v = x-y
```

> 什么时候想到：在所有 (i, j) 对中求 max / min；式子是几项 `|x_i - x_j|` 相加，项数少；n 大到 O(n²) 会超时。

第一次见很少有人能现场推出来，更现实的是认出这个模式。
