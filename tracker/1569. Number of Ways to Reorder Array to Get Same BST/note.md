# 1569. Number of Ways to Reorder Array to Get Same BST

## pass1

**题意**:`nums` 不是树的序列化(没有 index → 位置的规则,不是堆的 2i+1,也不是 LeetCode 层序 `[3,1,4,null,2,null,5]`),而是**插入顺序**。按顺序一个个插进 BST:第一个当根,后来的从根开始比大小,小往左、大往右,走到空位挂上;已放的节点永远不动。问还有几种**其他**排列能建出同一棵树 → 最后要 **-1**(去掉原数组本身)。

**例子** `[3,4,5,1,2]` → 5:
```
      3
    /   \
   1     4
    \     \
     2     5
```
3 必须第一;1 在 2 前;4 在 5 前;其余随便。3 后面 4 个位置选 2 个给左边 {1,2} → C(4,2) = 6,减原数组 = 5。

**为什么同一棵树**:一个数挂在哪,只取决于它往下走时路过的节点(祖先)。2 走 3 → 1,永远不往 3 右边走,4、5 在不在树上对它没影响。

**规则 = 祖先必须在后代前面,其余随便** → 这棵 BST 就是依赖树,答案是数它的拓扑序个数。
- 根必须第一:第一个插入的就是根
- 左右子树各自是同一个子问题:比根小的数一进来都往左,在左边那块空地上从头建 BST,谁先到谁是左子树的根
- 左右两组随便穿插:左边的数永远到不了右边,两组互相看不见,只要组内相对顺序不变,怎么交错树都一样
- 反例 `[3,2,1,4,5]`:2 先到,1 的位置还空着,2 抢走 3 的左孩子,树就变了

**公式**(L、R 为左右子树节点数):

$$
\text{ways}(T) = \binom{L+R}{L}\cdot \text{ways}(\text{左}) \cdot \text{ways}(\text{右}),\qquad \text{ways}(\varnothing) = 1
$$

答案 = ways(整棵) - 1,mod 1e9+7。

**等价闭式**:递归展开后组合数约掉,

$$
\text{ways}(T) = \frac{n!}{\prod_v \text{size}(v)}
$$

size(v) 为以 v 为根的子树大小。直觉:v 是自己子树那 size(v) 个数里最先出现的,概率 1/size(v),各节点独立。例子:5!/(5·2·1·2·1) = 6 ✓

**有公式,但不能直接从 nums 算**:闭式要每个节点的 size(v),得先知道树的结构。所以是两步:先求结构(建 BST 或递归切左右组,n ≤ 1000,链状最坏 O(n²) 也够),再套公式。和 1866 相反:斯特林数没闭式只能 DP;这题闭式干净,难在先拿到结构。

| | 递推式 C(L+R, L)·左·右 | 闭式 n!/∏size |
|---|---|---|
| 算什么 | 组合数,杨辉三角预处理,只有加法 | 模意义下的**除法** |
| 取模 | 每步直接 mod | 除 size 换成乘逆元,`pow(x, MOD-2, MOD)`(1e9+7 是质数) |

**实现(递推式版)**:
- 不用真建树:`[x for x in arr if x < root]` 保留原先后顺序,就是左子树的插入序列 = 子问题输入
- 递归深度:nums 有序时退化成链,深度 ≈ 1000,撞 Python 默认上限 → RecursionError
- 最后 `(ways(nums) - 1) % MOD`:ways 取模后可能恰好是 0,直接减会得负数

**组合数 `comb[a][b]` = $C_a^b$ = $\binom{a}{b}$**(a 总数,b 选几个;穿插数 $C_{L+R}^L$ = `comb[L+R][L]`)。递推盯最后一个元素,选 / 不选:

$$
C_a^b = C_{a-1}^{b-1} + C_{a-1}^{b},\qquad C_a^0 = 1
$$

- 例:$C_4^2$ = 选了 4($C_3^1$ = 3)+ 没选 4($C_3^2$ = 3)= 6
- `b = a` 时读 `comb[a-1][a]`,还是初始 0 = "a-1 个里选 a 个不可能",不用特判
- 画出来就是杨辉三角,跟 1866 的表同形状:每格只读上一行左上 + 正上,1866 正上那项多乘 (i-1)
