公式推导如下。我和暴力解对拍过所有 n ≤ 8、v ≤ 11 的组合，没有不一致的。

**拆成三部分**

峰值为 `v`，向两边每走一格减 1，减到 1 后保持不变。所以：

```
总和 = v + 左侧和 + 右侧和
左侧格子数 k = index
右侧格子数 k = n - 1 - index
```

左右两侧的算法完全相同，都是"从 `v-1` 开始依次减 1、最小为 1，共 k 个格子"，所以只需要写一个 `side(v, k)`。

**side(v, k) 分两种情况**

从 `v-1` 减到 1，一共有 `v-1` 个数。关键是比较 k 和 `v-1` 的大小：

**情况 1：`k <= v-1`。格子不够多，还没减到 1 就到边界了**

```
v=5, k=3:   [4, 3, 2]
```

这是一段完整的等差数列，首项 `v-1`，末项 `v-k`，共 k 项：

```
和 = (首项 + 末项) × 项数 / 2 = (v-1 + v-k) × k / 2 = (2v-1-k) × k / 2
```

**情况 2：`k > v-1`。格子够多，能减到 1，剩下的都是 1**

```
v=4, k=6:   [3, 2, 1, 1, 1, 1]
             └ 等差 ┘ └ 全是 1 ┘
```

- 等差部分是 `v-1, …, 1`，即 1 到 `v-1` 的和：`(v-1) × v / 2`
- 剩下 `k - (v-1)` 个格子，每个都是 1

```
和 = (v-1) × v / 2 + (k - (v-1))
```

**写成代码**

```python
def side(v, k):
    if k <= v - 1:
        return (2*v - 1 - k) * k // 2
    return (v - 1) * v // 2 + (k - (v - 1))
```

整数除法 `// 2` 不会丢精度。等差数列的和一定是整数，所以 `(首项+末项) × 项数` 一定是偶数。

下面是一张速查卡，分三部分。

**1. 数格子（下标从 0 开始）**

| 要数的 | 个数 |
|---|---|
| 闭区间 `[a, b]` | `b - a + 1` |
| 半开区间 `[a, b)` | `b - a` |
| 位置 `i` 左边 | `i` |
| 位置 `i` 右边（数组长 n） | `n - 1 - i` |
| 校验 | 左 + 右 + 1 = n |

记住闭区间那一行就够了，其他几行都能推出来。比如右边是 `[i+1, n-1]`，套用闭区间公式：`(n-1) - (i+1) + 1 = n-1-i`。

**2. 等差数列**

| 要算的 | 公式 |
|---|---|
| 求和 | `(first + last) * count // 2` |
| 1 + 2 + … + m | `m * (m + 1) // 2` |
| 第 count 项（公差 d） | `last = first + (count - 1) * d` |
| 项数 | `count = (last - first) // d + 1` |

递减数列的 d 是负数，例如从 `v-1` 往下数 k 项，末项是 `v-1 - (k-1) = v-k`。

代码里要先乘再 `// 2`。这样不会丢精度，因为 `(first + last) * count` 一定是偶数。

**3. 本题的模式：从 v-1 开始递减，最小为 1，共 k 格**

```python
cnt  = min(k, v - 1)                # 等差部分有几项（受格子数或"减到 1"限制）
sum_ = (v - 1 + v - cnt) * cnt // 2 + (k - cnt)
#       first   last                 剩下的全是 1
```

**题目牌组**

- **1802**：峰值为 v 时，一侧 k 格的最小和怎么算？
  - 正确思路：从 `v-1` 往下减，减到 1 后全补 1。`cnt=min(k,v-1)`，和为 `(v-1+v-cnt)*cnt//2 + (k-cnt)`。
  - 干扰项：从 v 开始减（把峰值也算进了这一侧）／这一侧全取 1（违反相邻差 ≤ 1）／直接用等差公式不截断（k 大时会减出 0 和负数）。
- **827**：翻转一个 0 时，怎么不重复计算？
  - 正确思路：先 flood fill，给每个岛编号（从 2 开始）并记面积；对每个 0，把四个邻居的编号收进 set，结果是 1 加上这些岛的面积和。
  - 干扰项：把岛的格子直接改成面积值／邻居面积直接相加、不去重／只把最大的那个岛加上。
- **1405**：贪心的每一步怎么选？
  - 正确思路：一次只放一个字符，按剩余个数从多到少，放第一个剩余不为 0、且不会三连的；都放不了就结束。
  - 干扰项：每轮放两个最多的，再插一个别的字符（就是你踩的 `bbb` 那个 bug）／按 a、b、c 固定顺序轮流放／最多的那个会三连时就直接结束。
