#### 🤖 Claude

说实话：**结果是对的，但不是最优。**

**复杂度**
- 你的写法：先 `sort` 再合并，是 **O(n log n)**。
- 最优是 **O(n)**。题目已经保证 `intervals` 有序且互不重叠，你 append 之后重新排序，等于把这个条件扔掉了。这道题考的就是怎么用上这个条件，面试官大概率会追问"能不能不排序"。
- 下界是 O(n)：输出本身就要 O(n)，所以就算用二分找边界，整体也快不过 O(n)。

**几个小问题**（不影响 AC）
1. `res[-1][0] = min(...)` 是多余的。排序之后 `res[-1][0] <= interval[0]` 一定成立，所以左端点不用更新。
2. 原地改了输入：`append` 和 `sort` 都会改动调用方传进来的 `intervals`。而且 `res` 里装的就是原来那些子列表，`res[-1][1] = ...` 会连带改掉输入里的元素。面试时最好提一句。

**O(n) 的提示**（按你的习惯先给提示，想看完整代码就说）

> 提示 1：把原列表按和 `newInterval` 的关系分成三段，从左往右扫一遍就能分完。

> 提示 2：三段分别是：完全在 new 左边、和 new 有重叠、完全在 new 右边。左段和右段原样放进结果；中间段只做一件事，就是不断把 `newInterval` 撑大。

> 提示 3：完全在左边的条件是 `cur.end < new.start`，完全在右边的条件是 `cur.start > new.end`。中间段结束后，把撑大的 `newInterval` 放进结果，再接右段。

建议先自己按提示 2 写一遍，再对照提示 3 检查边界条件（相邻端点相等时算不算重叠）。

#### 🤖 Claude

不会吞掉左段。原因是**往左扩最多扩一次，而且扩到的位置还在左段右边。**

**为什么左边吞不掉**

设左段最后一个区间是 L，中间段第一个区间是 M1。合并完以后左端点是 `s = min(new.start, M1.start)`，`s` 只可能等于这两个值之一，L.end 比两个都小：

1. 进左段的条件就是 `L.end < new.start`。
2. 原列表有序且互不重叠，L 排在 M1 前面，所以 `L.end < M1.start`。

所以 `s > L.end`，左段整体都在 `s` 左边，碰不到。

而且 `s` 在 M1 之后就不会再变了。中间段后面那些区间的 start 都比 M1.start 大，`min` 取不到它们。

**你担心的连锁扩张其实只发生在右边**

`e` 会被 M1 撑大，撑大后可能又碰到下一个区间，继续撑，一直传下去。中间段的 while 条件每轮都拿**最新的 `e`** 去比较，所以这种连锁会自然处理掉。等条件失败（`cur.start > e`），后面区间的 start 只会更大，也不会再重叠。

**例子**

`intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]]`，`new = [4,8]`

| 步骤 | 区间 | 判断 | s, e |
|---|---|---|---|
| 左段 | [1,2] | 2 < 4 | 4, 8 |
| 中间 | [3,5] | 3 ≤ 8 | **3**, 8（s 在这里扩，之后不会再变） |
| 中间 | [6,7] | 6 ≤ 8 | 3, 8 |
| 中间 | [8,10] | 8 ≤ 8 | 3, **10** |
| 停 | [12,16] | 12 > 10 | 右段 |

结果是 `[[1,2],[3,10],[12,16]]`。`s` 停在 3，没碰到 [1,2]；`e` 向右传到 10。

一句话：**往左扩只看中间段第一个区间，原列表互不重叠，所以不会吞掉左段；往右的连锁扩张由 while 条件实时更新的 `e` 处理。**

对了一半。这里其实是两件事，各靠一个条件：

| 结论 | 靠的条件 |
|---|---|
| `s` 最多变一次（只在 M1 那里变） | **有序**：后面区间的 start 都比 M1.start 大，`min` 不会再取到它们 |
| `s` 变了以后也碰不到左段 | **互不重叠**：`L.end < M1.start` |

你说的"之前的 interval 没 overlap"管的是第二件。

去掉"互不重叠"、只保留"有序"，就能看出两者的区别：

`intervals = [[1,4],[3,6]]`，`new = [5,7]`

- [1,4]：4 < 5，进左段
- [3,6]：3 ≤ 7，进中间段，`s = 3`。这里 `s` 还是只变了一次。
- 输出 `[[1,4],[3,7]]`，两个区间重叠，左段被吞了，算法出错。

所以 `s` 只扩一次靠的是有序，扩完不吞左段靠的是互不重叠。题目两个条件都给了，O(n) 的三段写法要两个一起用。
