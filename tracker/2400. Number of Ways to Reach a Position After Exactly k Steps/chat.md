2400 你已经做过了，sol.py 里有。回顾一下：

**题目**：在数轴上从 `startPos` 出发，每步向左或向右走 1，恰好走 k 步到达 `endPos`，问有多少种走法，结果模 10⁹+7。

**化成组合数**：设向右走 r 步、向左走 l 步，d = endPos − startPos，则

$$
r + l = k,\qquad r - l = d \;\Rightarrow\; r = \frac{k+d}{2}
$$

k 步里选出哪 r 步向右，答案就是 $C_k^{r}$。如果 |d| > k，或者 k + d 是奇数，就无解，返回 0。你的注释里两个反例都写了。

**"组合数取模模板"指的是什么**：你用的是 `math.comb(k, r) % MOD`，就是先用 Python 大整数把 C 精确算出来，最后再模。这道题 k ≤ 1000，这样能过，但这只是 Python 才能用的捷径：
- C(1000, 500) 大约有 300 位，C++ / Java 根本存不下。
- 如果要算很多个组合数，或者 n 到 10⁵ 这种规模，大整数会很慢。

所以这一组里把 2400 当作练习**手写 C(n,k) mod p** 的题，也就是这两套模板：

| 模板 | 做法 | 适用场景 |
|---|---|---|
| **杨辉三角** | `comb[a][b] = (comb[a-1][b-1] + comb[a-1][b]) % MOD`，只用加法 | n ≤ 几千，O(n²) 的表放得下。1569 你刚写过 |
| **阶乘 + 逆元** | 预处理 `fact[i]` 和 `inv_fact[i]`，算 $C_n^k$ = `fact[n] * inv_fact[k] * inv_fact[n-k] % MOD` | n 到 10⁵～10⁶，每次查询 O(1)。逆元用刚才说的 `pow(x, MOD-2, MOD)` |

第二套就是把刚才讲的"除法换成乘逆元"用到 $\frac{n!}{k!(n-k)!}$ 上。

杨辉三角你在 1569 已经手写过了。如果想把模板练完整，可以把 2400 的 `math.comb` 换成阶乘 + 逆元的写法再交一次，之后 1916 正好要用到它。

#### 🤖 Claude

$C_n^k$ 表示**从 n 个不同的东西里挑出 k 个、不管顺序，一共有几种挑法**。读作"n 选 k"，英文是 n choose k，也写成 $\binom{n}{k}$。

**公式**：

$$
C_n^k = \frac{n!}{k!\,(n-k)!}
$$

**为什么是这个式子**：
1. 先**按顺序**挑：第 1 个有 n 种选择，第 2 个有 n−1 种……第 k 个有 n−k+1 种。共 $n(n-1)\cdots(n-k+1) = \frac{n!}{(n-k)!}$ 种。
2. 但同一组 k 个东西，按不同顺序挑出来被重复数了 k! 次，而我们不管顺序，所以再除以 k!。

**例子**：$C_4^2$，从 {a, b, c, d} 里挑 2 个。
- 按顺序挑：4 × 3 = 12 种（ab 和 ba 算两种）。
- 不管顺序，除以 2! = 2，得 6 种：ab, ac, ad, bc, bd, cd ✓

**几个常用的值**：

| 式子 | 值 | 含义 |
|---|---|---|
| $C_n^0$ | 1 | 一个都不挑，只有空集这一种 |
| $C_n^n$ | 1 | 全部挑走 |
| $C_n^1$ | n | 挑一个，有 n 种 |
| $C_n^k = C_n^{n-k}$ | | 挑出 k 个要的，等于挑出 n−k 个不要的 |
| $k > n$ 时 | 0 | 不够挑 |

**今天用到的几处**：
- 2400：k 步里挑出哪 r 步向右，$C_k^r$。
- 1569：L+R 个位置里挑出哪 L 个给左子树，$C_{L+R}^L$。
- 杨辉三角递推 $C_n^k = C_{n-1}^{k-1} + C_{n-1}^k$：盯住第 n 个东西，分挑了它和没挑它两种情况。

**注意记号**：国内课本写成 $C_n^k$，总数 n 在下、挑几个 k 在上。也有些地方把上下标反过来写。$\binom{n}{k}$ 不容易看错，总数在上。

所以杨辉三角和阶乘 + 逆元是求comb的快速算法是吗

#### 🤖 Claude

差不多，但更准确的说法是：它们是**在取模下**求组合数的两种做法，重点在于**能取模**，"快"是其次。

直接按公式 $\frac{n!}{k!(n-k)!}$ 去算会遇到两个问题：
1. **数太大**：C(1000, 500) 大约 300 位，除了 Python 以外的语言都存不下。
2. **想边算边取模，但公式里有除法**：前面说过，除法不能直接取模。

两套模板分别这样绕开：

| | 杨辉三角 | 阶乘 + 逆元 |
|---|---|---|
| 怎么绕开除法 | 递推只用加法，根本没有除法 | 除法换成乘逆元 |
| 预处理 | O(n²)，打一整张表 | O(n)，算 `fact` 和 `inv_fact` 两个数组 |
| 每次查询 | O(1)，直接查表 | O(1)，三个数相乘 |
| 适用的 n | 几千以内，n² 的表放得下 | 10⁵～10⁶ |
| 对模数的要求 | 没有，任何模数都行 | 必须是质数，才能用费马小定理求逆元 |

它们"快"体现在**查询很多次的时候**：预处理一次，之后每个 C 都是 O(1)。1569 的递归里每一层都要查一个组合数，就很适合。如果整道题只算一个 C，像 2400，用哪种方法都差不多。

两者怎么选：
- n 小，或者模数不是质数 → 杨辉三角
- n 大，并且模数是质数（LeetCode 基本都是 10⁹+7）→ 阶乘 + 逆元

还有一种更少见的情况：n 比模数 p 还大，这时 n! 里含有因子 p，逆元就不存在了，要用 Lucas 定理。LeetCode 里基本碰不到，知道有这么回事就行。

#### 🤖 Claude

Python 里可以用 API，取模也没问题，只是它不会边算边模。

**能用的 API**：

| API | 作用 | 版本 |
|---|---|---|
| `math.comb(n, k)` | 用大整数精确算出 C，再自己 `% MOD` | 3.8+ |
| `pow(x, e, MOD)` | 模意义下的快速幂 | 一直都有 |
| `pow(x, -1, MOD)` | 直接求模逆元，不用自己写 `p-2` | 3.8+ |

标准库**没有**"带模数的 comb"。`math.comb` 只能先精确算出整个数，然后你再取模。因为 Python 的整数不会溢出，所以结果一定是对的。

**什么时候直接用 API 就行**：只算一个或少量组合数，并且 n 在几千以内。2400 就属于这种，`math.comb(k, r) % MOD` 完全够用。

**什么时候要手写**：
- **要查很多次，n 又很大**：比如 n 到 10⁵、查询 10⁵ 次。`math.comb` 每次都从头做一遍大整数乘法，会超时。预处理阶乘和逆元之后，每次查询是 O(1)。
- **1569 这种递归里频繁查询的**：用 `math.comb` 也能过（n ≤ 1000），但中间会算出几百位的大数，比查表慢。
- **换语言**：C++ 和 Java 都没有 comb API，数一大就溢出，只能手写。
- **面试**：可能会被要求手写，或者被问到"不用 Python 怎么做"。

**推荐的写法**：刷 LeetCode 时，题目简单就直接用 `math.comb`。但阶乘 + 逆元的模板最好自己会写一遍。逆元那一步可以用 `pow(x, -1, MOD)` 偷懒，只要知道它背后是费马小定理就行。

#### 🤖 Claude

这是**费马小定理**。最常见的证明是"乘一遍再重新排列"，用一个小例子就能看明白。

**例子**：p = 5，y = 2

把 1, 2, 3, 4 都乘以 2，再模 5：

| i | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 2i | 2 | 4 | 6 | 8 |
| 2i mod 5 | **2** | **4** | **1** | **3** |

得到的 2, 4, 1, 3 还是 1, 2, 3, 4 这四个数，只是**顺序被打乱了**。

既然是同样的四个数，那它们的乘积也一样：

$$
(2\cdot1)(2\cdot2)(2\cdot3)(2\cdot4) \equiv 1\cdot2\cdot3\cdot4 \pmod 5
$$

左边把四个 2 提出来：

$$
2^4 \cdot 4! \equiv 4! \pmod 5
$$

两边约掉 4!，得到 $2^4 \equiv 1$。验证：16 mod 5 = 1 ✓

**推广到一般情况**：把 y·1, y·2, …, y·(p−1) 都模 p，结果恰好是 1, 2, …, p−1 的一个重新排列。两边分别相乘，得到 $y^{p-1}(p-1)! \equiv (p-1)!$，约掉 (p−1)! 就是 $y^{p-1} \equiv 1$。

**关键一步：为什么只是打乱了顺序**。要说明两件事：
- **不会出现 0**：p 是质数，i 和 y 都不是 p 的倍数，所以乘积 iy 也不是 p 的倍数。
- **不会撞车**：如果 iy ≡ jy，那么 p 整除 (i−j)y。p 是质数又不整除 y，所以只能整除 i−j。而 i 和 j 都在 1 到 p−1 之间，所以 i = j。

p−1 个结果互不相同，又都落在 1 到 p−1 里，那只能是把这 p−1 个数各取一次。

**质数这个条件用在哪**：上面两步都用了"质数整除乘积，就一定整除其中一个因数"。最后约掉 (p−1)! 也要依赖它，因为 (p−1)! 里没有 p 的因子，模 p 下才能约。

**模数不是质数时会失败**：m = 4，y = 3，3 × {1, 2, 3} = 3, 6, 9，模 4 得 3, **2**, 1。看起来像是重新排列，但如果 y = 2：2, 4, 6，模 4 得 2, **0**, 2，既出现了 0 又撞了车。整个推理就不成立了。1337 = 7 × 191 也是这个原因，所以 372 不能用这一招。

**和逆元的关系**：$y^{p-1} = y \cdot y^{p-2} \equiv 1$，所以 $y^{p-2}$ 就是 y 的逆元。

#### 🤖 Claude

我上一条用的叫**剩余系重排法**，英文一般叫 the multiplicative proof 或 proof by rearrangement。核心是：把 1 到 p−1 都乘以 y，模 p 后只是同一组数换了顺序，所以两边乘积相等，再约掉 (p−1)!。这在数论里叫"简化剩余系乘一个与 p 互质的数，仍然是简化剩余系"。欧拉定理的证明也用同一招。

费马小定理还有另外几种常见证法：

| 证法 | 思路 | 适合谁 |
|---|---|---|
| **剩余系重排**（上一条） | y·{1..p−1} 是 {1..p−1} 的重新排列，两边相乘再约掉 | 最常用，初等数论课本的标准证法 |
| **二项式定理 + 数学归纳** | $(y+1)^p \equiv y^p + 1 \pmod p$，因为中间的 $C_p^i$（0<i<p）都能被 p 整除。从 $1^p \equiv 1$ 一路推到 $y^p \equiv y$，再约掉 y | 和组合数这条线直接相关 |
| **项链计数**（组合证明） | 用 y 种颜色给 p 颗珠子的项链染色：除去 y 种纯色的，其余 $y^p - y$ 种按旋转每 p 个一组，所以 p 整除 $y^p - y$ | 最直观，不用任何代数 |
| **群论 / 拉格朗日定理** | 模 p 的非零数在乘法下构成一个 p−1 阶的群，任何元素的阶都整除群的阶，所以 $y^{p-1} = 1$ | 最短，但需要群论背景 |

第二种和你现在练的组合数很有关系。它的关键是：当 p 是质数、0 < i < p 时，$C_p^i = \frac{p!}{i!(p-i)!}$ 的分子里有 p，而分母里的因子都小于 p 约不掉它，所以 $C_p^i$ 是 p 的倍数。展开 $(y+1)^p$ 时中间各项模 p 都是 0，只剩 $y^p + 1$。
