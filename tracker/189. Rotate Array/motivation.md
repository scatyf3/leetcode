1. 从"旋转到底是什么"出发

向右转 k 位，本质是把数组切成两块然后交换顺序：


[1,2,3,4 | 5,6,7]   →   [5,6,7 | 1,2,3,4]
   A          B              B      A
也就是 AB → BA。问题变成：怎么在原地把两段交换位置？

2. 关键恒等式：BA = reverse(reverse(A) + reverse(B))

这是一个值得记住的通用技巧（不只用于这题）。验证一下：


A = [1,2,3,4]   B = [5,6,7]
reverse(A)          = [4,3,2,1]
reverse(B)          = [7,6,5]
拼起来 reverse(A)+reverse(B) = [4,3,2,1,7,6,5]
再整体反转           = [5,6,7,1,2,3,4] = BA  ✓
为什么成立？反转会把拼接顺序倒过来：reverse(X + Y) = reverse(Y) + reverse(X)。所以
reverse( reverse(A) + reverse(B) ) = reverse(reverse(B)) + reverse(reverse(A)) = B + A。

reverse 两次抵消，正好还原每段内部顺序，只是把 A、B 的位置换了。

代码里我先做整体反转、再分别反转两段，顺序反过来做也等价——核心就是这条恒等式。

3. 怎么"想到"用反转
几个可迁移的信号：

要求 O(1) 空间 → 不能开新数组 → 只能靠"交换/翻转"这类原地操作。
"移动一段" / "交换两段顺序" → 反转是最省空间的段操作原语。字符串旋转（"abcde" 左移 2 位）、单词反转（"the sky is blue" → "blue is sky the"）都是同一个套路。
一旦脑子里有了 AB → BA 这个抽象，就会去回忆"有没有 O(1) 把两段换位的办法"，反转法自然浮现。
4. 建议的记忆方式
不要记"反转三次"这个动作，记这条规律：

交换相邻两段的位置 = 各自反转 + 整体反转（或整体反转 + 各自反转）。

记住规律，动作可以现场推。这道题、字符串左右旋转、翻转句子里的单词，全是它。
