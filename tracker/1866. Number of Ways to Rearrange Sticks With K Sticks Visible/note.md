# 1866. Number of Ways to Rearrange Sticks With K Sticks Visible


用dp递推。
## pass1
**想法**：看有几根被挡住，把遮盖关系组织成组，再排。方向对：每根看得见的和它后面被它挡住的打包成一组，k 根看得见 ⇔ 分成 k 组。但两处是被迫的：
- 组内最高的必须站第一个，其余随便排 → s 根一组 (s-1)! 种，不是 s!
- 组之间只能按组头从矮到高排 → 不能再乘 k!

**分组直接数不好算 → DP，盯最矮那根**（代码在 sol.py）：
- 单独一组：组头最矮，一定在最左边，看得见 → `dp[i-1][j-1]`
- 插在别人后面：被挡住，有 i-1 个位置 → `(i-1) * dp[i-1][j]`

填空踩的坑：
- `dp[0][0] = 1`，不是 0（空排列算一种，`dp[1][1]` 靠它）
- 内层 `range(1, min(k, sticks) + 1)`，漏了 `seen == sticks`
- 两个分支存的是**排法数**（查表），不是木棍数；整段没读过 dp 旧值就不是 DP
- `return dp[n][k]`，不是 `[n+1][k+1]`

**c(n, k) 是第一类斯特林数**，不是组合数 C(n, k)：n 人坐 k 张圆桌，一组 = 一张桌。c(4,2) = 11，C(4,2) = 6。
- 没有公式：组的大小怎么分会影响数量，c(4,2) 里 3+1 有 8 种、2+2 只有 3 种，只能分情况加
- 特殊 k 有：c(n,n) = 1，c(n,1) = (n-1)!，c(n,n-1) = C(n,2)
- 也是 x(x+1)…(x+n-1) 展开后 x^k 的系数，一个括号一个括号乘开就是这个 DP
