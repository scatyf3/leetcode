## 判回文的预处理，这段有什么问题

```python
def isPalindrome(self, s: str) -> bool:
    s = s.lower()
    s = "".join(c for c in s if c.isalpha())
    return s == s[::-1]
```

---

`isalpha()` **漏掉数字**。题目要的是"字母**和**数字"，该用 `isalnum()`。

```python
"0P".lower()                                  # "0p"
"".join(c for c in "0p" if c.isalpha())       # "p"   ← 数字被扔了
"p" == "p"[::-1]                              # True  ← 错，正确答案是 False
```

这个坑**解释器不会报错**，OJ 也只回你一句 Wrong Answer —— 属于反馈最慢的那一类，
所以值得单独做张卡。三兄弟：

| | 收什么 |
|---|---|
| `c.isalpha()` | 只有字母 |
| `c.isdigit()` | 只有数字 |
| `c.isalnum()` | 字母**或**数字 ← 判回文/清洗输入要的是这个 |

## 这两行跑完，s 变了吗

```python
s = "A man, a plan"
s.lower()
s.replace(" ", "")
print(s)
```

---

**没变**，打印出来还是 `"A man, a plan"`。

str 是**不可变**的，所有"修改"方法都是**返回新字符串**，原串纹丝不动。想生效必须接住：

```python
s = s.lower()                  # ✔ 覆盖回去
s = s.replace(" ", "")         # ✔
```

顺带一串**根本不存在**的方法（别的语言的肌肉记忆）：

- `s.tolowercase()` / `s.toLowerCase()` → 是 `s.lower()`（对应 `s.upper()`）
- `s.remove(" ")` → str 没有 `remove`，那是 list 的。删字符用 `s.replace(" ", "")`
- `s.reverse()` → str 没有；反转用切片 `s[::-1]`（`list.reverse()` 才是原地的）

这类打错方法名的，解释器 0.2 秒就甩 `AttributeError` 给你，反馈够快，**不值得背**。
真正要记住的是上面那条不可变 —— 它不报错，只是静默不生效。

## 想"只保留字符串里符合条件的字符"，怎么写

---

**开列表推导筛完再 `join` 回去** —— 不能原地删，str 不可变。

```python
s = "".join(c for c in s if c.isalnum())
```

写 `[c for c in s if ...]`（列表）和 `(c for c in s if ...)`（生成器）都行，
`join` 两个都吃。习惯用生成器：少建一个中间列表。

思路的转折点：**别想"删掉哪些"，想"保留哪些"**。
`replace(" ", "")` 那条路要你把逗号、冒号、问号一个个列全，列漏一个就错；
筛选式只需要说清一个正向条件。

⚠️ 这一步是 **O(n) 额外空间**（新串和原串同阶）。题目卡 O(1) 空间时不能这么预处理，
改成双指针边走边用 `isalnum()` 跳 —— 见 [125 的 sol2.py](../125.%20Valid%20Palindrome/sol2.py)。

栽过：125

## 想判断"字符是字母或数字"，用哪个方法

---

`c.isalnum()`。

同族的还有 `isalpha()`（只字母）、`isdigit()`（只数字）、`isspace()`（空白）、
`islower()` / `isupper()`。都是**判断整个字符串**的，对单字符调只是最常见的用法：

```python
"abc123".isalnum()    # True  —— 整串都是字母数字
"abc 123".isalnum()   # False —— 有空格
"".isalnum()          # False —— 空串一律 False，别指望它当"没有非法字符"用
```

最后那条是边界坑：空串在所有 `isXXX()` 上都返回 `False`。

栽过：125

## 想反转字符串 / 取倒数第二个字符，怎么写

---

```python
s[::-1]      # 反转（str 没有 reverse()）
s[-2]        # 倒数第二个
s[:-1]       # 去掉最后一个字符
s[-3:]       # 最后三个
```

切片**永远不越界**：`"ab"[:100]` 是 `"ab"`，不报错。
但**下标会**：`"ab"[5]` 直接 `IndexError`。所以双指针的右端是 `len(s) - 1`，不是 `len(s)`。

`s[::-1]` 是新建一个反转的串 → **O(n) 空间**。判回文时 `s == s[::-1]` 写着爽，
但要 O(1) 空间就得老实用双指针。

栽过：125
