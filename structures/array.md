# Array 通用 trick

数组的能力：**随机访问 O(1)、有下标顺序**。大多数技巧都是在利用「下标」和「顺序」做文章。

下标(indexing)是这里的核心，最容易犯的错误是off-by-one，防止此错误的方法是在写index的时候想一下「我当前的index是开还是闭，当前index是即将处理的，还是最近一个已经处理的」

二维数组多出「行列对称性、邻接关系、层/圈结构」三样东西，单独一篇：[matrix.md](matrix.md)。

## 0. 索引与切片约定（半开区间）

按照大部分编程语言的约定，我们的切片(slice)是左开右闭区间。如做一个cover array全部元素的切片，写作 `[0,len(lst)]`

1. **合法下标**：`0 .. len(lst)-1`。下标 `len(lst)` 根据契约，描述的是「第一个尚未处理 / 无效的尾部下标」）的下一个（虽然在array里后面无了，但在其他切片理由）
2. **切片是半开的**：`lst[0:len(lst)]` 取整个数组，右端 `len(lst)` 只是「越过末尾」的边界，不指向真实元素。记住 `[start:end)` —— 含头不含尾。

为什么要有这个契约？在这个契约里，右边界同时描述三件事：
- **下一个要写入的位置** (next element to write)
- **已有的合法元素个数** (number of valid elements)
- **要返回的值** (value to return)

同一套约定在二维上的版本见 [matrix.md](matrix.md) §0；把「缝」当成二分的搜索空间
（`r` 取 `n` 不取 `n-1`）见 [paradigms/binary-search.md](../paradigms/binary-search.md)
「另一套半开区间模板」，35 / 704 就是它。

## feature

given一个array，我们可以思考几个问题：
1. 有无顺序，或者partial顺序(有序+rotate k)
2. 有无重复
3. index本身有无意义，如果index有意义，类似桶排序，用index做key 比naive hash更好
4. 范围
  1. 有没有0，有0导致乘法不可逆
  2. 有没有负数，负数导致乘法要维护俩极值
  3. 是否范围很小，能拿来桶排序(3)
6. in place or not
7. 是否是区间[s,e]，这部分参见 [[xxx]]
8. stream, 295，这里的特点是给你一个按时序的1d元素，用途不明

返回：
1. 是否存在？t/f，某个value？
2. 切片，这里都是坑
  1. 细节
    1. 切片让你返回value还是index
    2. 这个切片是是否要求连续，有的会不要求连续！(subseq vs subarray)
  2. 切片本身，切片本身的expend是否可逆
    1. substr/sum 统计，可逆
    2. 有0乘法，... 不可逆
  3. 这个切片变化边界的时候怎么reset状态，l++？l跳转到某个index？l=r？

## 在array上的题型

### 1. 双指针 (two-pointer)

此类方法不限定于array，其他1d结构如string也能操作，但是以目前观测，在array里出现最频繁，根据的.

这里双指针有若干要回答的问题：
1. initial state和运动方向，分三个case
    1. 都在start ➡️➡️
    2. 一个start 一个end ➡️⬅️
    3. 基于某些中心扩散 ⬅️➡️
2. 对应两者同向运动还是相向运动
    1. 相向运动
    2. 同向怎么做iteration
        - 一个快一点一个慢一点, 外层loop l(slow)，内层loop r(fast)
        - 内层loop是skip没有意义的，还是贪婪添加，直到第一个没有意义的
    3. reset
        - l++？
        - l跳转到某个index？
        - l=r？

同一个序列上，按两个指针怎么动分四族：

| 运动 | 在 array 上长什么样 | `r−l` 有意义吗 | 我的题 |
|------|--------------------|--------------|--------|
| 同向·快慢 | 慢指针 = 下一个写入位，原地删/搬元素 | 无意义 | 26, 27 |
| 同向·滑窗 | 连续子段的最优 | **就是答案**（窗口长度） | 3, 424 |
| 相向·夹逼 | （先排序）找一对 / 一组元素 | 通常无关；11 是封顶量 | 11, 15, 42, 167 |
| 相背·扩散 | 从中心往两边，对称结构 | **就是答案**（回文长度） | 5, 647 |

两个指针各在一个序列上则是第五族**归并型**（21 / 23 / 88），它不排除候选，
O(n) 只来自「每个元素读一次」，正确性论证和上面四族完全不同，别混。
88 在 array 上的特产是**从后往前填**，避开覆盖未读数据。

选型和论证都不在这篇：四族各自靠什么保证正确（夹逼的支配论证、滑窗的合法性向下封闭、
扩散的收缩封闭）、拿到新题的五步选型、各族的坑，见
[paradigms/two-pointer.md](../paradigms/two-pointer.md)。
其中「快慢指针的慢指针有三重身份」就是上面 §0 半开区间约定的直接应用（§2「同向·快慢」），
「候选丢不掉只能汇总 → 那是 DP 不是双指针」则接到 [paradigms/1d-dp.md](../paradigms/1d-dp.md)。

### 2. 反转 (reversal)

`交换相邻两段的位置 = 各自反转 + 整体反转`

- 右旋 k 位：反转全部 → 反转前 k → 反转后 n-k（189 Rotate Array）
- O(1) 空间的「段交换」原语，字符串旋转、翻转单词同理。

同一个原语升到二维就是「转置 + 反转 = 旋转」，见 [matrix.md](matrix.md) §3 —— 48 Rotate Image 就是它。

### 3. 前缀 / 后缀预处理

对每个位置预存「左边的累积量」或「右边的累积量」：前缀和、前缀最大、后缀最大…

- 42 接雨水：每个位置的水 = min(左max, 右max) - 高度。
  这题还有个不用预处理数组的相向夹逼版，论证见 [paradigms/two-pointer.md](../paradigms/two-pointer.md) §2「相向·夹逼」。
- **能砍掉数组吗？** 见下条 §4；压不掉的典型（238 前缀积 × 后缀积）见
  [paradigms/1d-dp.md](../paradigms/1d-dp.md) §5「两个压不掉的典型」。

### 4. 滚动变量压缩 (rolling variable)

如果「枚举方向」和「依赖方向」一致，那一侧的极值/累加值只需一个**标量**边走边滚，不必存整个数组。

- 121 买卖股票：枚举卖出日（从左往右），只依赖左边最小值 → `min_so_far` 一个变量，O(1) 空间。
- 自检：① 枚举哪个点？② 向哪个方向要信息？③ 能否让枚举方向=依赖方向？能 → 数组降成标量。

这三问是简版。完整的**四问**（第 ④ 问来自 238 的复盘）、机械流程、以及「方向相反不一定压不掉」
和「什么时候压缩本身就不该做」，都在 [paradigms/1d-dp.md](../paradigms/1d-dp.md) §5「滚动压缩」。

### 5. 贪心 vs DP（在数组上）

- 有**贪心选择性质**（每步赢家当场唯一确定、可加、互不牵制）→ 贪心（122 吃所有上坡）。
- 候选要回头比较、依赖后续 → DP（打家劫舍）。
- 「只依赖前 k 步」决定的是能否滚动压缩空间，**与贪心/DP 无关**。

这三条的完整论证在 [paradigms/1d-dp.md](../paradigms/1d-dp.md) §4「贪心 = 退化的 DP」——
那边的口径是「贪心是候选数被压到 1 的 DP」，顺着这条还能再退一步到 scan。
状态定义的两种口径、多分量状态见同一篇 §2 / §3。

### 6. 其它常用

- **差分数组**：区间批量加，O(1) 打标记、最后一次前缀和还原。
  → [paradigms/intervals.md](../paradigms/intervals.md) §3「扫描线 / 差分」，那边是把它当事件流用。
- **原地哈希**：值域 = 下标范围时，用符号位/交换把数组自己当哈希表（缺失的第一个正数）。
  同一个「拿容器自己当额外空间」的招在二维上是 [matrix.md](matrix.md) §4「原地标记」。
- **滑动窗口**：连续子数组 / 子串的最优，双指针维护窗口。
  正确性靠的是**合法性向下封闭**（窗口合法 ⇒ 它的任意子窗口也合法），
  见 [paradigms/two-pointer.md](../paradigms/two-pointer.md) §2「同向·滑窗」—— 3 / 424 就是它。
