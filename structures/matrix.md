# Matrix 通用 trick

二维数组本质还是数组（见 [array.md](array.md)），但多了一维之后出现三类数组没有的东西：
**行列两个方向的对称性**、**邻接关系（上下左右）**、**层/圈的嵌套结构**。
下面按「这个 trick 在利用哪一条」来组织。

## 0. 索引约定

**永远用 `r` / `c`，不要用 `x` / `y`。**

因为索引写法是 `matrix[r][c]` —— 行在前、列在后。而 `x`/`y` 的数学直觉是「x 横、y 纵」，
一旦这么命名，索引就得写成 `matrix[y][x]`，**读起来是反的**，非常容易写错。

```python
m, n = len(matrix), len(matrix[0])     # m 行 n 列
for r in range(m):
    for c in range(n):
        ...matrix[r][c]
```

- 合法下标：`0 <= r < m` 且 `0 <= c < n`
- 空矩阵防御：`if not matrix or not matrix[0]: return ...`（`len(matrix[0])` 会在 `[]` 上炸）
- **一维 / 二维互转**：`idx = r * n + c`，反向 `r, c = divmod(idx, n)`
  —— 把 m×n 矩阵当成长度 m*n 的一维数组，就能直接套二分（74 搜索二维矩阵）

## 1. 四边界法（层/圈）

维护 `top, bottom, left, right` 四个**闭区间**边界，描述「还没走过的矩形」。
每走完一条边就收缩对应的那个边界。

```
while top <= bottom and left <= right:
    →  沿 top 行 left..right        走完 top++
    ↓  沿 right 列 top..bottom      走完 right--
    ←  沿 bottom 行 right..left     走完 bottom--     (需守卫 top <= bottom)
    ↑  沿 left 列 bottom..top       走完 left++       (需守卫 left <= right)
```

**两个必踩的坑**：

1. **后两趟必须各加守卫**。进 `while` 时只验过一次，第 2 趟后 `top`/`right` 都动过了，
   剩余矩形可能已经空掉。不加守卫时 `[[1,2,3]]` 会输出 `[1,2,3,3,2,1]`。
   前两趟不需要守卫，因为 `while` 条件刚刚才验过。
2. **倒序 range 要写步长**：`range(right, left - 1, -1)`。漏掉 `-1` 得到的是**空 range**，
   不报错、只是默默少走一圈 —— 这类 bug 最难发现。

自测用例固定这两个：`[[1,2,3]]`（单行）、`[[1],[2],[3]]`（单列）。能打掉绝大多数错误实现。

典型题：54 螺旋矩阵、59 螺旋矩阵 II（同模板，把 append 换成赋值 1..n²）。

> **不要为「现在走到第几条边」设一个变量。** 四个顺序排列的 `for` 循环里，
> 「在哪个循环里」本身就是这个状态，程序计数器已经存好了。
> 能用控制流表达的状态就别提成变量 —— 提成变量就多一处要维护、要判断、会写错的地方。

## 2. 方向数组（邻接 / 网格搜索）

当转向时机**不固定**（撞墙才转、或要向四周全部扩散）时才用它。

```python
DIRS = [(-1, 0), (1, 0), (0, -1), (0, 1)]              # 上 下 左 右
DIRS8 = DIRS + [(-1,-1), (-1,1), (1,-1), (1,1)]        # 加四个对角

for dr, dc in DIRS:
    nr, nc = r + dr, c + dc
    if 0 <= nr < m and 0 <= nc < n and ...:            # 边界检查永远第一个写
        ...
```

- **边界检查必须在访问 `matrix[nr][nc]` 之前**，且 Python 的 `and` 是短路的，顺序不能反
- 负数下标在 Python **不报错**（`matrix[-1]` 是最后一行），所以 `0 <= nr` 这半边不能省 —— 
  漏了它不会崩，只会静默地从对面绕回来
- 典型题：417 太平洋大西洋水流、200 岛屿数量、79 单词搜索

**和四边界法怎么选**：转向时机确定（螺旋）→ 四边界，不需要额外空间；
转向靠试探（撞墙/撞访问过的格子）→ 方向数组，但必须有 visited 或原地标记（见 §4）。

## 3. 转置 + 反转 = 旋转（行列对称性）

方阵专属。任何 90°/180° 旋转和翻转都能拆成「转置」和「反转」的组合，全部 O(1) 空间：

| 目标 | 分解 |
|------|------|
| 顺时针 90° | 转置 → 每**行**反转 |
| 逆时针 90° | 转置 → 每**列**反转（等价于反转行的顺序） |
| 180° | 每行反转 → 每列反转 |

```python
for r in range(n):                                     # 转置: 只走上三角
    for c in range(r + 1, n):
        matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
for row in matrix:
    row.reverse()
```

**转置的内层循环必须从 `r+1` 开始**。写成 `range(n)` 会把每对元素交换两次，等于没换。

这条和 [array.md](array.md) §2 的「交换两段 = 各自反转 + 整体反转」是同一个思想：
**把一个难写的整体变换，拆成若干个好写的原语**。典型题：48 旋转图像。

## 4. 原地标记（拿矩阵自己当额外空间）

题目要 O(1) 空间时，常见手法是把信息编码回矩阵本身：

- **改值当 visited**：200 岛屿数量，DFS 走过就把 `'1'` 改成 `'0'`（沉岛），省掉 visited 矩阵
- **借第一行/第一列当标记位**：73 矩阵置零，把「这行/这列要清零」记在 `matrix[r][0]` 和 
  `matrix[0][c]` 上。注意第一行和第一列**自己**是否要清零得单独用两个变量记，否则会互相覆盖
- **用符号位**：值域非负时，把 `matrix[r][c]` 取负表示「已访问」，最后统一取回绝对值

代价是**破坏输入**。面试时先问一句「可以修改输入吗」。

## 5. 阶梯搜索（利用行列双有序）

行内升序、列内也升序的矩阵（240 搜索二维矩阵 II），**从右上角开始**：

```python
r, c = 0, n - 1
while r < m and c >= 0:
    if matrix[r][c] == target: return True
    elif matrix[r][c] > target: c -= 1      # 这一整列都太大, 砍掉
    else: r += 1                            # 这一整行都太小, 砍掉
```

O(m+n)。**关键在于选对起点**：右上角是同时位于「所在行最大、所在列最小」的位置，
所以一次比较必然能砍掉一整行或一整列。左下角同理可行；左上/右下角**不行**——
那两个角上比较的结果无法排除任何一整行或列。

这是「支配论证」在二维上的翻版，和 [paradigms/two-pointer.md](../paradigms/two-pointer.md)
里左右夹逼敢丢端点的理由是同一个：被砍掉的那些格子，上限已经结算完了。

注意区分 74（整个矩阵按行展平后全局有序）用 §0 的一维下标转换直接二分 O(log mn)，
比阶梯搜索更快 —— 两题条件不同，别套错。
