### 核心逻辑

怎么理解我错误理解了核心逻辑的mindset 缺陷，我知道要算l和r，但我忘了要如何使用它们
每个位置能装的水 = min(左边最大高度, 右边最大高度) - 当前高度\

错误思路
先算出所有中间结果，再想怎么用 看数据的规律 → 试图匹配

正确思路
先明确最终公式，再算所需的中间值 明确目标 → 设计算法

但是从数据找规律是对的解法吗，还是从highlevel直接推，我认为我习惯前者

你的"从数据找规律"不是坏习惯，它对培养直觉很有价值。但要补两个环节：

规律必须验证：提出假设后，一定用具体例子跑一遍
规律要能解释：如果一个规律你说不清"为什么成立"，它大概率是错的或不完整的（比如你的"相邻不变=有水"，你能解释背后的原因吗？解释不了，就是危险信号）

### for loop

我们需要一个左/右 max的for loop，比普通的for loop不一样的是刚开始的第一个元素没人比较，需要特殊处理，一个写起来比较简单的的写法是
```python
# 计算每个位置左边的最大高度
L[0] = height[0]
for i in range(1, n):
    L[i] = max(L[i-1], height[i])

# 计算每个位置右边的最大高度
R[n-1] = height[n-1]
for i in range(n-2, -1, -1):
    R[i] = max(R[i+1], height[i])
```
