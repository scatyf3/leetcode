### for loop

我们需要一个左/右 max的for loop，比普通的for loop不一样的是刚开始的第一个元素没人比较，需要特殊处理，一个写起来比较简单的的写法是
```python
# 计算每个位置左边的最大高度
L[0] = height[0]
for i in range(1, n):
    L[i] = max(L[i-1], height[i])

# 计算每个位置右边的最大高度
R[n-1] = height[n-1]
for i in range(n-2, -1, -1):
    R[i] = max(R[i+1], height[i])
```

总感觉接雨水和接水有谜之联系，他俩的相似之处和区别是？
同一个数组 `[1,8,6,2,5,4,8,3,7]`：11 的答案是 49（`min(8,7)*7`，取 l=0,r=8），42 的答案是 19（2+6+3+4+4）。同样的输入、同样的"水"、同样的双指针，答案毫无关系——说明相似的只是外壳。

**相似之处**
1. 输入都是柱状图 `height[]`，目标都是"水"，暴力解都是 O(n²) 枚举 (l, r) 对。
2. 都能压到 O(n)/O(1) 的双指针，且移动规则都是"谁小挪谁"。
3. 底层都是**短板原理**：结果由 `min(左, 右)` 决定，长的那边的具体数值在当前这一步是无关信息。

**区别**

| | 42 接雨水 | 11 盛水容器 |
|---|---|---|
| 目标 | 所有位置水量**求和**（可分解到每一格） | 单个矩形面积**求最值**（不可分解） |
| 中间柱子 | 既挡水又占体积 | 完全忽略（容器无底、中间不挡） |
| 宽度 | 每格宽 1，距离不进入公式 | 面积 = 距离 × min(h)，距离是主角 |
| 依赖范围 | 每格依赖**远处**的全局最大值 → 需要前缀/后缀 max 把远处信息搬到手边 | 只依赖**手上这两根** → 没有远处可搬，不需要预处理 |
| 范式 | 预处理统计量（退化的一维 DP） | 贪心/排除法 |

**双指针的语义完全不同（这是最容易混的地方）**
- 42 的指针移动是**结算**：`Lmax < Rmax` 时，位置 i 的水位 `min(Lmax,Rmax)` 已被 Lmax 锁死，右边再怎么变都不影响，所以可以当场把这一格的水加进答案。指针必须走完每一格，一格都不能漏，因为答案是累加。
- 11 的指针移动是**剪枝**：移动短板意味着"以这根短板为边界的所有 pair 全部作废"——宽度只会更小、高度不会超过短板，一次淘汰 O(n) 个候选。指针跳过的位置是被证明不可能更优，不是被结算。

所以：42 是"用短板**定案**"，11 是"用短板**排除**"。两者都是在 (l, r) 的二维搜索空间上靠单调性把 O(n²) 降成 O(n)，但一个在求和、一个在求最值。

**一个检验理解的思想实验**：如果给 11 加上"中间柱子会挡水"的规则，贪心立刻失效（被淘汰的窄 pair 可能因为中间没有阻挡反而更优）；反过来，把 42 限制成"只保留两根柱子、中间铲平"，它就退化成 11。
