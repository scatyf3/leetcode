旋转数组永远
```
下标   0  1  2  3  4  5  6
值     4  5  6  7  0  1  2
       └─ 大段 ─┘  └小段┘
                   ↑ 最小值在这
```

拿 nums[mid] 和最后一个数比。

最后一个数(这里是 2)一定属于小段。所以:

nums[mid] > 2 → mid 落在大段里 → 最小值在它右边 → l = mid + 1
nums[mid] < 2 → mid 落在小段里 → 最小值在它左边或就是它 → r = mid
