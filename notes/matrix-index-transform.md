## 先分清两个方向的映射

这是最容易绕晕的地方,任何时候先约定清楚你要哪一个:

- **正向(push)**:老位置 `(i,j)` 的值应该去哪 → `new[?][?] = old[i][j]`
- **反向(pull)**:新位置 `(i,j)` 该从哪取 → `new[i][j] = old[?][?]`

两者互为逆映射。写循环时用哪个都行,**但混用必错**。下面所有表默认 `n x n`,下标 `0..n-1`。

## 四个基本变换(push 形式)

| 变换 | 映射 `(i,j) →` | 人话 |
|---|---|---|
| 主对角线转置 `T` | `(j, i)` | 沿 `↘` 对折 |
| 副对角线转置 `T'` | `(n-1-j, n-1-i)` | 沿 `↙` 对折 |
| 水平翻转 `FlipH` | `(i, n-1-j)` | **每行反转**,左右镜像 |
| 垂直翻转 `FlipV` | `(n-1-i, j)` | **每列反转**,上下镜像 |

记法:**下标里出现 `n-1-x`,就是那一维被翻转了;`i` 和 `j` 换位,就是转置了。**

## 四个旋转(由基本变换复合而来)

| 旋转 | push:`(i,j) →` | pull:`new[i][j] =` | 分解成两趟 |
|---|---|---|---|
| 顺时针 90° | `(j, n-1-i)` | `old[n-1-j][i]` | **转置 + 每行反转** |
| 逆时针 90° | `(n-1-j, i)` | `old[j][n-1-i]` | **转置 + 每列反转** |
| 180° | `(n-1-i, n-1-j)` | `old[n-1-i][n-1-j]` | 每行反转 + 每列反转 |
| 360° | `(i, j)` | — | 什么都不做 |

复合是怎么算出来的,以顺时针 90° 为例——把第一步的结果代进第二步:

```
转置:      (i,j) → (j,i)
每行反转:  (a,b) → (a, n-1-b)     把 (a,b) = (j,i) 代入
合起来:    (i,j) → (j, n-1-i)     ✓
```

顺序可以换,`FlipV` 再 `T` 得到的是同一个式子(自己代一遍验证)。但 `T` 再 `FlipH` 和 `FlipH` 再 `T` **不是**同一个东西——变换不交换,顺序必须记牢。

## 30 秒验一遍(每次都要做)

别信推导,信例子。拿 `n=3` 的 `[[1,2,3],[4,5,6],[7,8,9]]`,顺时针 90° 应得 `[[7,4,1],[8,5,2],[9,6,3]]`:

- 追 `(0,0)` 的 `1`:公式给 `(0, n-1-0) = (0,2)`,输出里 `1` 确实在 `(0,2)` ✓
- 再追一个**非对称**的点,比如 `(0,1)` 的 `2`:公式给 `(1,2)`,输出 `new[1][2] = 2` ✓

只验 `(0,0)` 不够——对角线上的点在很多变换下位置相同,验不出转置和旋转的区别。**至少追一个 `i≠j` 的点。**

## in-place 怎么做

**方案 A:两趟(推荐先写这个)**

转置(只遍历上三角 `j > i`,否则会转两次转回去)+ 每行反转。代码最短,不用想环。

**方案 B:四元环**

旋转映射的**阶是 4**——连续套 4 次回到原点。所以每个元素属于一个 4 元环:

```
(i,j) → (j, n-1-i) → (n-1-i, n-1-j) → (n-1-j, i) → 回到 (i,j)
```

只需要 **1 个临时变量**就能把这 4 个位置轮转好。遍历范围只取左上角一块:

```python
for i in range(n // 2):
    for j in range((n + 1) // 2):
        ...
```

注意**不是对称的** `n//2 x n//2`:`n` 为奇数时中心点自成一环(不用动),但中间那一行/列的其余点必须被覆盖。`n=3` 时左上角该取 **2** 个点(`(0,0)` 和 `(0,1)`),不是 1 个。取错了就会漏掉一整圈。

## 非方阵

`m x n` 旋转 90° 后形状变成 `n x m`,**不可能 in-place**(LC 48 限定方阵正是为了这个)。pull 形式仍然好用:

```
顺时针:  new[i][j] = old[m-1-j][i]      # new 是 n x m
逆时针:  new[i][j] = old[j][n-1-i]
```

转置同理,`m x n → n x m`。

## 附:两条对角线的下标恒等式

不是旋转,但同属「矩阵下标」这一族,经常一起考:

- `i + j` 为常数 → 同一条**副对角线**(`↙` 方向),取值 `0 .. 2n-2`
- `i - j` 为常数 → 同一条**主对角线**(`↘` 方向),取值 `-(n-1) .. n-1`,做数组下标时偏移成 `i - j + n - 1`

用在 N 皇后(LC 51)判冲突、对角线遍历(LC 498)、对角线排序(LC 1329)。
