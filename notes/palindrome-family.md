# 回文题全家:一个骨架 + 两条分水岭

适用题:LC 5、647、516、1312、131/132、214、9、125、680。

配套:[off-by-one-checklist.md](off-by-one-checklist.md)(索引不出错)、[sliding-window-template.md](sliding-window-template.md)(对照:为什么回文套不上滑窗)

## 先把最贵的一条记住:回文有**两种**封闭性,方向相反

绝大多数回文题的解法选择,都能从这一条推出来:

| 封闭方向 | 是否成立 | 后果 |
|----------|----------|------|
| **同心收缩**:`s[l..r]` 回文 ⟹ `s[l+1..r-1]` 回文 | ✅ 成立 | 中心扩展的 while 可以放心 break;二分半径成立 |
| **任意取子串**:`s[l..r]` 回文 ⟹ 其任意子串回文 | ❌ 不成立(`"aba"` → `"ab"`) | **滑动窗口彻底失效** |

- 第一条的逆否命题 = 半径 k 扩失败 ⟹ k+1 也失败 ⟹ **while 停下时后面没有漏网之鱼**。这就是中心扩展只跑 O(n²) 而不是 O(n³) 的全部理由。
- 第二条是滑窗的前提(合法性向下封闭 ⟹ 收缩一定安全 ⟹ 左边界单调)。回文不满足,所以左边界不单调,窗口爬不动。

> 拿到任何新题,先问这两句,而不是先想解法。

## 分水岭 1:子串(连续) vs 子序列(可跳)

**这条决定你能不能用中心扩展。**

| | 子串(连续) | 子序列(可跳着取) |
|---|---|---|
| 题 | 5、647、131、214 | 516、1312 |
| 中心扩展 | ✅ 主力 | ❌ **彻底失效**(没有连续区间可"扩") |
| 区间 DP | 可用(更差) | ✅ 唯一常规解 |
| `f[i][j]` 的含义 | **是否**回文(bool) | 最长回文子序列**长度**(int) |

看到"子序列"三个字就别再想中心了,直接上 DP。

## 分水岭 2:结算方式(骨架完全不变)

LC5 和 LC647 是**同一份代码**,差别只在结算那一行:

```python
def expand(l, r):
    while l >= 0 and r < n and s[l] == s[r]:
        # ← 【填空位】结算放这里(647: cnt += 1)
        l -= 1
        r += 1
    # ← 【填空位】或者结算放这里(5: return s[l+1:r])
```

| 题 | 结算 | 有没有 ±1 |
|---|---|---|
| **5** 最长回文子串 | 退出后取区间 `s[l+1 : r]` | 有(1 次,已搬到切片语法里) |
| **647** 回文子串计数 | 循环内 `cnt += 1` | **0 次** |

**推论:能在循环内结算的,就别留到循环外结算。** 循环内结算时指针还是合法的,压根不用关心"while 退出时指针停在第一个不合法位置"这件事——省掉的是一整类 off-by-one,不是一行代码。见 [off-by-one-checklist.md](off-by-one-checklist.md)。

## 骨架 A:中心扩展(子串题的默认答案)

O(n²) 时间 / O(1) 空间。**2n-1 个中心**:n 个奇中心(轴是字符)+ n-1 个偶中心(轴是缝)。

```python
n = len(s)

def expand(l, r):
    while l >= 0 and r < n and s[l] == s[r]:
        ...                       # 填空位: 结算
        l -= 1
        r += 1
    return ...

for i in range(n):
    expand(i, i)                  # 奇中心 -> 奇数长度
    expand(i, i + 1)              # 偶中心 -> 偶数长度
```

三个必记的点:

1. **漏偶中心是本类题最常见的 WA。** 把两次调用写在相邻两行,让"漏了"肉眼可见。
2. **偶中心不用任何特判。** `s[i] != s[i+1]` 或 `i+1 == n` 时,while 首轮就退出,自然返回空/0。让非法输入退化,别写 `if`。
3. **`expand` 该封装**(同题内调用 2 次且内部不变),这和 [sliding-window-template.md](sliding-window-template.md) 里论证 `Window` 类**不该**封装并不矛盾——判据是「同一道题内调用次数 ≥ 2 且内部不随场景变」,不是代码量。

## 骨架 B:区间 DP(子序列题的唯一解 / 子串题的备胎)

O(n²) 时间 / O(n²) 空间。**真考点是遍历顺序,不是转移方程**:`f[i][j]` 依赖 `f[i+1][j-1]`(左下方格子),双层正序会读到还没算的值,**必须按区间长度递增**(或 i 倒序)。

判定型(LC5 / 647):

```python
f = [[False] * n for _ in range(n)]
for i in range(n):
    f[i][i] = True
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        if s[i] == s[j] and (length == 2 or f[i + 1][j - 1]):
            f[i][j] = True
            ...                   # 填空位: 647 计数 / 5 记录最长区间
```

长度型(LC516,已对拍验证):

```python
f = [[0] * n for _ in range(n)]   # f[i][j] = s[i..j] 内最长回文子序列的长度
for i in range(n):
    f[i][i] = 1
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        if s[i] == s[j]:
            f[i][j] = (f[i + 1][j - 1] if length > 2 else 0) + 2
        else:
            f[i][j] = max(f[i + 1][j], f[i][j - 1])   # ← 判定型没有这一支
return f[0][n - 1]
```

两个填空位的区别一句话:**判定型两端不同就是 False;长度型两端不同要取 max(丢左 / 丢右)**。

## 题目地图

| 题 | 类型 | 主解法 | 一句话 |
|---|---|---|---|
| **5** 最长回文子串 | 子串 | 中心扩展 | 骨架 A,退出后取区间 |
| **647** 回文子串计数 | 子串 | 中心扩展 | 骨架 A,循环内计数,零 ±1 |
| **516** 最长回文子序列 | 子序列 | 区间 DP(长度型) | 等价于 LCS(s, reverse s)(已对拍) |
| **1312** 最少插入变回文 | 子序列 | = `n - LPS(s)` | 做完 516 是一行(已对拍) |
| **131** 分割回文串 | 子串 | 回溯 + 骨架 B 预处理 | 先建 `f[i][j]` 表,回溯里 O(1) 查 |
| **132** 分割回文串 II | 子串 | 线性 DP + 同一张表 | 求最少切割次数 |
| **214** 最短回文串 | 前缀 | KMP / Manacher | 找最长回文**前缀**,中心扩展射程外 |
| **9** 回文数 | 数字 | 反转一半 | 别转字符串,别整个反转(溢出) |
| **125 / 680** 验证回文串 | 双指针 | 头尾夹逼 | 680 失配时分叉试删左/删右 |

**Manacher(O(n))面试不要求**,当收集品。它的两个 trick:插 `#` 把偶回文变奇回文(统一中心)、用最右回文的镜像继承初始半径(摊还 O(n))。结算换一下就能同时解 5 和 647:LC5 取 `max(p)`,LC647 取 `sum((p[i]+1)//2)`。实现见 [5. sol3.py](../5.%20Longest%20Palindromic%20Substring/sol3.py) 和 [647. sol4.py](../647.%20Palindromic%20Substrings/sol4.py)。

## 一个已被证伪的"网红解法"

"求 s 和 reverse(s) 的**最长公共子串**"来解 LC5 是**错的**——公共子串不保证来自同一位置。反例 `"abacdfgdcaba"` 给出 `"abacd"`(不是回文)。详见 [5. note.md](../5.%20Longest%20Palindromic%20Substring/note.md)。

(注意别和 516 混:**子序列**版 `LCS(s, reverse(s)) == LPS(s)` 是**对的**,已对拍 2000 组。同一个套路在子串上错、在子序列上对。)

## 速记

1. 先判两条封闭性:同心收缩 ✅(能中心扩展)/ 任意子串 ❌(不能滑窗)
2. 子串 → 中心扩展;子序列 → 区间 DP。看到"子序列"就别想中心
3. 中心有 2n-1 个,奇偶两行写在一起,偶中心不需要特判
4. 骨架不变,只换结算:取最长 / 计数 / 判定建表
5. 能在循环内结算就别留到循环外——省掉一整类 off-by-one
6. 区间 DP 的考点是**按长度递增**遍历,不是转移方程
